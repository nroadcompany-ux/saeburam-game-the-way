# THE WAY MVP — 최종 범위 정의

**Version:** v2.0 CRITICAL  
**Date:** 2026-06-10  
**Principle:** 작은 완성 > 큰 미완성

---

## 🎯 MVP의 진정한 목표

**100개 사건 구현이 아니다.**

**365개 질문 구현이 아니다.**

**커뮤니티도 아니다.**

**다국어도 아니다.**

---

## ✅ MVP의 진정한 목표는

### 첫 번째 사용자가

```
1. 감정을 선택하고
2. 말씀을 만나고
3. 기도를 남기고
4. Legacy를 저장하는 것

이 4단계를 완벽하게 구현하는 것.
```

# 📋 MVP 범위 (명확한 정의)

## ✅ MVP에 포함 (필수)

### Stage 1: 감정 선택
```
SCREEN 01: Emotion Spectrum Slider

사용자:
- 감정 선택 (슬라이더 또는 세부 선택)
- 강도 선택 (1-5)

기능:
✅ 9개 감정 표시
✅ 슬라이더 인터랙션
✅ SessionStorage 저장

NOT:
❌ 추가 감정 (9개 이상)
❌ 감정 커스터마이징
```

### Stage 2: 말씀 만남
```
SCREEN 03-05: 성경 사건 선택 & 읽기

사용자:
- 추천 사건 선택 (3-5개)
- 성경 사건 읽기
- 하나님의 질문 직면

기능:
✅ 6개 대표 사건 (감정별 1개씩)
✅ 각 사건의 핵심 말씀 표시
✅ 하나님의 질문 제시

NOT:
❌ 100개 전체 사건
❌ 365개 질문
❌ 사건별 상세 배경 설명
❌ 신학적 깊이 (너무 많은 해석)
```

### Stage 3: 기도 남기기
```
SCREEN 08: 기도 입력

사용자:
- 성경을 읽은 후 기도 입력
- 깨달음 기록
- 순종 계획 입력

기능:
✅ 텍스트 입력 (500자)
✅ 자동 저장
✅ SessionStorage + localStorage

NOT:
❌ 음성 기도
❌ 이미지 삽입
❌ 공동 기도
```

### Stage 4: Legacy 저장
```
SCREEN 10-11: 기록 & 간증

사용자:
- 1주일 후 변화 기록
- 간증 입력
- 비공개 저장 (기본)

기능:
✅ 6개 항목 저장 (날짜/감정/기도/깨달음/순종/간증)
✅ 1년 데이터 보기 (기본 통계)
✅ 비공개 기본 설정

NOT:
❌ 5년 보기 (v1.1)
❌ 공개 프로필 (v1.1)
❌ 커뮤니티 공유 (v2.0)
```

# 🎯 MVP 핵심 메시지

## "작은 완성 > 큰 미완성"

```
나쁜 접근:
└─ 100개 사건 + 365개 질문 + 커뮤니티 + 다국어
   결과: 모두 미완성, 아무것도 깊지 않음

좋은 접근 (THE WAY MVP):
└─ 1명의 사용자가 감정 → 기도 → Legacy
   완벽하게 구현
   결과: 깊이 있는 경험, 확장 가능한 기반
```

- 질문 은행 확대
- 추적 가능한 질문

5. Event Recommendation (추천)

NOT MVP:

# 🎬 MVP 사용자 여정

## 첫 방문 (Cold Start)
```
Time: 20분

SCREEN 01: 감정 선택
- 슬라이더로 "슬픔" 선택

SCREEN 02: 강도 선택
- ●●●○○ (Level 3)

SCREEN 03: 기도 입력 (선택)
- "하나님, 너무 외롭습니다"

SCREEN 04: Whisper
- "너는 혼자가 아니다"
- 출처: 시편 56:8

SCREEN 05: 추천 사건
- "나오미의 이야기"

SCREEN 06-08: 성경 읽기 & 깨달음
- 나오미 사건 읽기
- 깨달음 입력: "나오미도 혼자라고 생각했다"
- 기도: "제게도 하나님이 있나요?"

SCREEN 09: 순종 계획
- "이번 주 친구에게 연락하기"

SCREEN 10-11: Legacy 저장
- 기록 저장 (비공개)

결과:
"이건 뭐야? 성경이 나를 알고 있네?"
→ 호기심 생김
```

## 1주일 후
```
Time: 30분

사용자 앱 다시 열기
(새로운 감정 또는 순종 기록)

SCREEN 01-11 반복
(이번엔 "분노" 감정)

SCREEN 10-11: 간증 기록
- 1주일 전 순종 결과 기록
- "친구에게 연락했다. 친구도 같은 기분이었다"

결과:
"내가 변했네?"
→ 의미감 생김
```

## 12개월 후
```
SCREEN 12: Legacy 1년 보기 (기본)

데이터:
- 52번 순환 완료
- 52개 간증 기록
- 감정 변화: 슬픔 5→2, 외로움 4→1
- 순종 성공률: 80%+

결과:
"하나님이 나를 이렇게 변화시키셨다"
→ 영적 깊이 생김
```

# 🎨 MVP 디자인 원칙

```
1. 단순함
   └─ 각 스크린 1가지 역할만

2. 명확함
   └─ 뭘 하는지 3초 안에 이해

3. 깊이
   └─ 한 가지를 완벽하게

4. 반복 가능성
   └─ 사용자가 계속 돌아올 수 있게

5. 의미
   └─ 포인트나 레벨이 아니라 변화 추적
```

# ✅ MVP 성공 기준

## 완성도
```
✅ 1명의 사용자가
  ① 감정 선택
  ② 말씀 만남
  ③ 기도 남김
  ④ Legacy 저장
  
  이 4단계를 완벽하게 경험할 수 있는가?
```

## 깊이
```
✅ 각 단계가 깊이 있는가?
  - 단순 기계적 입력이 아닌가?
  - 영혼의 변화가 일어나는가?
  - 사용자가 "의미"를 느끼는가?
```

## 반복성
```
✅ 사용자가 다시 올 이유가 있는가?
  - 새로운 감정이 계속 생기는가?
  - 매번 경험이 깊어지는가?
  - 기록이 쌓이면서 의미가 증가하는가?
```

## 확장성
```
✅ 이 4단계를 확장할 수 있는가?
  - 6개 → 100개 사건
  - 6개 → 225개 Whisper
  - 기본 → 5년 데이터 보기
  - 비공개 → 선택적 공개
```
