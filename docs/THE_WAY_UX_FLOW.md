# PART 1. 설계 원칙

## 1.1 헌법 기반 UX 원칙

| 헌법 원칙 | UX 적용 |
|---------|--------|
| **LAW 01** — 여정 우선 | 목적지 없음. 평생 진행되는 흐름 설계 |
| **LAW 02** — 수단과 목적 | 버튼, 메뉴, 화면은 모두 "회심"으로 수렴 |
| **LAW 03** — 만남 우선 | 설명보다 질문, 지시보다 초대 |
| **LAW 04** — 여정 구조 | 질문→깨달음→회개→순종→변화→기록 을 시각적으로 표현 |
| **LAW 07** — 현실 순종 최고 | 게임 내 클리어보다 현실 퀘스트 강조 |
| **ENGINE 07** — Legacy | 모든 기록은 영구 저장. 삭제 불가 원칙 |

## 1.2 UX 핵심 3원칙

### ① 설교하지 않는다
```
❌ "이 결정은 회개의 첫 단계입니다"
✅ [질문만 표시] + [선택 옵션]
```

### ② 강요하지 않는다
```
모든 화면에 "건너뛰기" 옵션 존재
- 회개 도중에도 나갈 수 있음
- 현실 퀘스트를 안 할 수도 있음
- 하지만 질문은 계속 따라옴 (로그인할 때마다)
```

### ③ Legacy는 영구 기록
```
❌ 기록 삭제 버튼
✅ 기록 수정 버튼만 (원본 보존 + 수정 이력)
```

## 3.2 각 섹션 상세

### ① 오늘의 하나님 질문
**목적:** 매일 새로운 만남의 기회

```
원리:
1. CORE_BIBLE_100에서 랜덤 선택 (또는 시리즈)
2. 플레이어 Awakening Stage별로 같은 사건도 다른 깊이의 질문
   - Stage 1 (입문): 직관적 질문
   - Stage 3 (씨름): 깊은 질문
   - Stage 5 (증인): 타인을 위한 질문
3. 오전 8:00 (설정 가능) 갱신
4. 건너뛰면 내일 다시 나타남
```

### ② 나의 진행 상황
**목적:** 자신의 변화를 시각화

```
표시 항목:
- Awakening Stage (1~5): 진행 단계
  ▶ 숫자 말고 "입문", "각성", "씨름", "동행", "증인" 이름으로
  
- 총 Wisdom: 누적 포인트
  ▶ "경험치" 같이 보이지 않게
  ▶ "깨달음의 흔적" 같이 표현
  
- 연속 진행: 몇 일 연속 진입했는가
  ▶ "12일 연속 여정 중" (칭찬 톤)
```

### ③ 계속하기
**목적:** 마지막 지점으로의 빠른 복귀

```
방식:
- 마지막 진행 챕터 표시
- 진행률 표시 (%)
- 한 탭으로 이어서 진행
```

### ④ 기록 (Legacy 최신)
**목적:** "당신의 이야기가 소중하다" 메시지

```
표시:
- 가장 최근 기록 (텍스트 미리보기)
- 그때의 Wisdom Point
- [전체 기록 보기] 링크
```

# PART 8. Legacy 기록 방식

## 8.1 자동 vs 수동

### 자동 생성 시점
- Chapter 완료 시 (의무)
- 현실 퀘스트 완료 시 (선택적)

### 수동 기록
- "자유로운 기도" 메뉴
- 언제든 추가 가능
- "일기" 같은 느낌

## 8.2 기록의 생명 주기

```
생성 (자동 또는 수동)
    ↓
저장 (즉시 영구 저장)
    ↓
보존 (절대 삭제 불가)
    ↓
수정 가능 (원본 보존 + 수정 기록)
    ↓
10년 뒤
    ↓
회상 (자신의 영적 자서전)
    ↓
증인 (타인과 공유 - 선택적)
```

## 8.3 삭제 불가 원칙의 UX

```
기록 화면:

┌──────────────────────┐
│ 001 | 아담과 하와     │
│                      │
│ [수정하기] [아카이브] │
│ [삭제 불가 ○]       │
│ "이 기록은 당신의   │
│  영적 자서전입니다" │
└──────────────────────┘

해석:
"삭제가 아니라 '진실'입니다"
```

# PART 9. 회개 반복 검출 & Discernment 연동

## 9.1 패턴 인식

```
시스템이 감지:
- 같은 종류의 회개가 5회 이상 반복
- 예: "자부심 때문에 용서 못함" (003, 015, 027, 035, ...)

트리거:
→ Discernment Engine 질문 제공
→ "이게 반복되는 이유가 뭘까요?"
→ 근본 원인 탐색 가이드

화면:
"당신의 패턴 발견"
```

   아니면 다른 두려움이 숨어 있을까요?"

❓ "이 깨달음이 정말 하나님께 온 것이라면,
   왜 같은 실수를 반복하고 있나요?"

❓ "회개 후 변하지 않는다면,
