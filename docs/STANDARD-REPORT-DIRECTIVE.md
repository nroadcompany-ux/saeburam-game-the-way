# 표준 작업 보고 지시서

날짜: 2026-06-12
지위: 운영 표준 (CLAUDE.md에서 참조)

> 목적: "어떻게 됐어?"라고 되묻지 않도록, 모든 작업을 **같은 형식 + 시각 표시**로 자동 보고한다.

---

## 1. 자동 보고 원칙

1. **별도 요청이 없어도** 작업이 끝나면 아래 표준 형식으로 보고한다.
2. 모든 보고 최상단에 **보고 시각(KST)** 을 표시한다.
   - 시각은 추측하지 않는다. 매 턴 주입되는 `[현재 시각 — 보고 타임스탬프용]` 값을 그대로 사용한다.

---

## 2. 표준 보고 형식

```
🕐 보고 시각 : YYYY-MM-DD HH:MM KST
📋 작업      : <한 줄 요약>
─────────────────────────────
✅ 완료 내역 :
   - …
📁 변경 파일 :
   - path/to/file  (신규 / 수정 / 이동)
🌿 브랜치    : <branch>   |   커밋: <short-sha>
⚠️ 주의/리스크:
   - … (없으면 "없음")
⏭️ 다음 제안 : <다음 추천>
```

- 변경이 없거나 단순 질의면 `📋 작업` + `✅ 완료 내역`만 축약 가능.
- 시각 줄(`🕐`)은 **어떤 경우에도 생략하지 않는다.**

---

## 3. 시각 표시 동작 원리

- `.claude/settings.json`의 **UserPromptSubmit 훅**이 매 메시지마다
  `TZ=Asia/Seoul date`로 현재 KST를 컨텍스트에 주입한다.
- 원격/웹 세션은 시작 시 저장소를 새로 복제하므로, 커밋된 이 설정은
  **다음 세션부터 시작 시점에 자동 적용**된다.
