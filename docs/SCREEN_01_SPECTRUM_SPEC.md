# SCREEN 01-A: Spectrum Slider (1초 결정)

## 레이아웃

```
┌─────────────────────────────────┐
│                                 │
│     오늘 나는                    │
│                                 │
│    😩 기분이야                  │  ← 동적 업데이트
│                                 │
│  무기력    혼란    감정선택 감사  평안
│  ◄────────●───────────────────►  ← Slider
│  부정                        긍정
│                                 │
│     [이렇게 시작할래]           │
│     [더 정확하게 고르기]         │
│                                 │
└─────────────────────────────────┘
```

## 슬라이더 매핑

### 감정 스펙트럼 배치 (좌 → 우)

```
X축: 0 ─────────────── 50 ─────────────── 100
     부정적          중립            긍정적

감정 배치:
  0:  무기력 😩  (가장 부정적)
 12:  슬픔 😢
 25:  두려움 😨
 37:  분노 😠
 50:  외로움/혼란 🥀  (중립점)
 62:  죄책감 😔
 75:  감사 🙏  (긍정으로 전환)
 87:  평안 ☮️  (가장 긍정적)

참고: 비기독교인이 많으므로
     "감사", "평안" = 종교적으로 안 들리게
     슬라이더 위치로만 판단
```

## 동적 텍스트 업데이트

```typescript
// Slider 값 → 감정명 매핑
const emotionMap = {
  0: '무기력',
  12: '슬픔',
  25: '두려움',
  37: '분노',
  50: '혼란',
  62: '죄책감',
  75: '감사',
  87: '평안',
};

// Display:
"오늘 나는 [감정명] 기분이야"
```

### 시간별 텍스트 변화 예시

```
사용자 슬라이드 진행:

[처음] "오늘 나는 무기력한 기분이야"
        [●─────────────────────]

[드래그 중] "오늘 나는 슬픈 기분이야"
            [──●──────────────────]

[계속] "오늘 나는 분노한 기분이야"
       [────────●────────────────]

[오른쪽] "오늘 나는 평안한 기분이야"
         [───────────────────────●]
```

## UI 컴포넌트 상세

### 1. 헤더 텍스트
```
텍스트: "오늘 나는"
폰트: Inter, 20px, Medium (500)
색상: #F5F1E8 (cream)
마진: 상단 40px
```

### 2. 감정명 + 이모지 (동적)
```
감정명: "기분이야" 빈칸에 채워짐
이모지: 슬라이더 값에 따라 변경 (24px)
폰트: 감정명 28px, Bold (700)
색상: #D4AF37 (gold - 강조)
애니메이션: Fade in/out (150ms) 감정 변경 시

예시 HTML:
<div className="emotion-display">
  <span className="text">오늘 나는</span>
  <span className="emoji">{emotionEmoji}</span>
  <span className="name">{emotionName}</span>
  <span className="text">기분이야</span>
</div>
```

### 3. 슬라이더
```
길이: 280px (화면 너비 375px - 좌우 margin 47.5px × 2)
높이: 48px (전체 터치 영역)

트랙:
  높이: 4px
  배경색: #D4C8B8 (sub-text, 20% opacity)
  
썸: (●)
  크기: 24px × 24px
  배경색: #D4AF37 (gold)
  그림자: 0 2px 8px rgba(0,0,0,0.3)
  터치 확대: hover시 28px (scale 1.2)

레이블:
  좌측: "부정" (13px, #D4C8B8)
  우측: "긍정" (13px, #D4C8B8)
  
감정명들:
  슬라이더 아래 9개 감정명 미니 표시 (9px, 중복 제거)
  예: 무기력  슬픔  두려움  분노  ...  평안
```

### 4. 버튼 그룹

스타일: Primary (gold)

#### 버튼 B: "더 정확하게 고르기" (Secondary)

# SCREEN 01-B: Detailed Selection (선택사항)

## 목표
사용자가 **정확한 감정**을 선택하도록 세부 옵션 제공.

## 레이아웃

```
┌─────────────────────────────────┐
│  오늘 나는                       │
│  [현재 슬라이더값] 기분이야     │
│                                 │
│  더 정확하게 말해주세요          │
│  (모두 선택 가능합니다)         │
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ [  ] 슬픔 😢            │   │
│  │ [  ] 두려움 😨          │   │
│  │ [  ] 분노 😠            │   │
│  │ [●] 외로움 🥀   ← 기본 │   │
│  │ [  ] 죄책감 😔          │   │
│  │ [  ] 무기력 😩          │   │
│  │ [  ] 혼란 🤔            │   │
│  │ [  ] 감사 🙏            │   │
│  │ [  ] 평안 ☮️            │   │
│  └─────────────────────────┘   │
│                                 │
│  [선택 완료]                    │
│                                 │
└─────────────────────────────────┘
```

## 특징

### 다중 선택 가능
```
사용자가 여러 감정 선택 가능:
  [●] 슬픔
  [●] 외로움
  [  ] 두려움
  
선택된 감정들 → Screen 02로 전달
```

### 기본값
슬라이더에서 가장 가까운 감정이 기본 체크됨.

예시:
```
슬라이더 값: 50 (혼란 근처)
→ "혼란" 자동 체크
→ 사용자가 추가로 "슬픔", "외로움" 선택 가능
```

### 취소 옵션
```
[◄ 슬라이더로 돌아가기]  (왼쪽 상단)
→ SCREEN 01-A로 복귀
```

# 🎬 상호작용 플로우

## Flow 1: 슬라이더만 사용 (1초)
```
사용자 진입
    ↓
슬라이더 기본값 설정 (중앙 = 혼란, 50)
    ↓
"오늘 나는 혼란한 기분이야" 표시
    ↓
[이렇게 시작할래] 클릭
    ↓
SCREEN 02로 진행 (감정 강도 선택)
```

## Flow 2: 세부 선택 사용 (5초)
```
사용자 진입
    ↓
슬라이더 조정 (예: 왼쪽으로 → 무기력)
    ↓
[더 정확하게 고르기] 클릭
    ↓
9개 감정 라디오 버튼 또는 체크박스
    ↓
[●] 무기력, [●] 슬픔 선택
    ↓
[선택 완료] 클릭
    ↓
SCREEN 02로 진행
```

# 💾 데이터 구조

## Session State (선택 저장)

```typescript
interface Screen01Selection {
  method: 'slider' | 'detailed';  // 어느 방법으로 선택했는지
  sliderValue: 0-100;             // 슬라이더 최종값
  emotionIds: string[];           // 선택된 감정 ID 배열
  emotions: {
    id: string;
    name: string;
    emoji: string;
  }[];
  timestamp: ISO8601;
}

// 예시 1: 슬라이더만 사용
{
  method: 'slider',
  sliderValue: 50,
  emotionIds: ['confusion'],
  emotions: [{ id: 'confusion', name: '혼란', emoji: '🤔' }],
  timestamp: '2026-06-10T14:30:00Z'
}

// 예시 2: 세부 선택 사용
{
  method: 'detailed',
  sliderValue: 0,
  emotionIds: ['exhaustion', 'sadness'],
  emotions: [
    { id: 'exhaustion', name: '무기력', emoji: '😩' },
    { id: 'sadness', name: '슬픔', emoji: '😢' }
  ],
  timestamp: '2026-06-10T14:30:00Z'
}
```

## 다음 Screen으로 전달
```
SCREEN 02 (감정 강도)로:
  - emotionIds: ['confusion'] 또는 ['exhaustion', 'sadness']
  - emotions: 선택된 감정 메타데이터
  
SCREEN 02에서는:
  "당신이 선택한 [감정들]의 강도는?"
  → 각 감정별로 1-5 강도 선택
```

# ♿ 접근성 (Accessibility)

## 키보드 네비게이션
```
Tab: 슬라이더 → 버튼 A → 버튼 B
화살표 키 (←→): 슬라이더 값 조정 (-1/+1 또는 -5/+5)
Enter/Space: 버튼 클릭
```

## 스크린 리더
```
슬라이더:
  aria-label="감정 스펙트럼 슬라이더"
  aria-valuetext="오늘 나는 혼란한 기분이야"
  aria-valuenow={sliderValue}

버튼:
  aria-label="이렇게 시작할래. 선택한 감정으로 진행"
```

## 색상 대비
```
텍스트 vs 배경: #F5F1E8 on #1A1F3A
비율: 12.5:1 (WCAG AAA 기준, 4.5:1 이상)

gold 버튼: #D4AF37 on #1A1F3A
비율: 5.2:1 (WCAG AA 기준)
```

# 🎬 애니메이션 & 미디어

## 슬라이더 애니메이션
```
드래그 중: 
  - 감정명 Fade out (50ms)

  - 이모지 Scale 1.0 → 1.1 (100ms)

터치 피드백:
  - 슬라이더 썸 scale 1.0 → 1.2 (100ms)
```

```

  - 배경색 변경 (200ms, ease-out)
  - Scale 1.0 → 1.02 (100ms)

클릭:
  - Scale 1.02 → 0.98 (50ms)
  - 복귀 (100ms)
```
