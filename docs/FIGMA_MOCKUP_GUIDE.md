## 1️⃣ 헤더 섹션 (Y: 0~140)

### 1.1 컨테이너
- **Frame 이름:** Header
- **크기:** 375 × 140
- **배경:** #1A1F3A
- **패딩:** 좌 24px, 우 24px

### 1.2 제목 텍스트
```
텍스트: "오늘 당신의 마음은\n어떠한가요?"
폰트: Inter, 28px, Semi Bold (600)
색상: #F5F1E8 (크림)
위치: X 24, Y 30
정렬: Left
라인 높이: 36px
```

### 1.3 부제목 텍스트
```
텍스트: "꺼지지 않는 질문이 있습니다"
폰트: Inter, 13px, Regular (400)
색상: #D4C8B8 (서브텍스트)
위치: X 24, Y 105
정렬: Left
```

## 2️⃣ 카드 스택 섹션 (Y: 160~590)

### 2.1 카드 컨테이너
- **Frame 이름:** Card Stack
- **크기:** 375 × 430
- **배경:** 없음 (투명)

### 2.2 각 카드 스펙

#### 카드 기본 설정
```
프레임 이름: Card - [감정이름]
크기: 320 × 350
모서리: 반경 20px (모든 모서리)
그림자: Drop Shadow
  - 오프셋: 0, 10
  - 블러: 30px
  - 불투명도: 30%
```

#### 카드 배치 (카드 스택 효과)
```
카드 1: X: 27.5, Y: 0
카드 2: X: 52.5, Y: 18 (약간 아래로)
카드 3: X: 77.5, Y: 36 (더 아래로)
```

#### 카드 내용 (각 카드별)

**감정 1: 두렵다**
```
배경색: #1A2847 (진한 파란색)

요소:
1. 아이콘 (X: 20, Y: 20)
   텍스트: 😨
   폰트: 48px

2. 감정 이름 (X: 20, Y: 80)
   텍스트: "두렵다"
   폰트: Inter, 24px, Semi Bold (600)
   색상: #F5F1E8

3. 구분선 (X: 20, Y: 125)
   직사각형: 280 × 1px
   색상: #D4C8B8 (투명도 20%)

4. 질문 텍스트 (X: 20, Y: 145)
   텍스트: "당신은 이 순간\n무엇을 두려워하는가?"
   폰트: Inter, 16px, Regular (400)
   색상: #F5F1E8
   라인 높이: 24px

5. 버튼 배경 (X: 20, Y: 270)
   직사각형: 260 × 45px
   배경색: #D4AF37 (황금색)
   모서리: 반경 10px

6. 버튼 텍스트 (X: 20, Y: 279)
   텍스트: "경험하기"
   폰트: Inter, 16px, Semi Bold (600)
   색상: #1A1F3A
   정렬: Center (260px 너비 내)
```

**감정 2: 화가 난다**
```
배경색: #2A1F1F (어두운 적색)

요소:
1. 아이콘: 😠
2. 감정 이름: "화가 난다"
3. 질문: "당신의 분노는\n어디서 비롯되었는가?"
(나머지는 감정 1과 동일한 구조)
```

**감정 3: 외롭다**
```
배경색: #1F2340 (자주색)

요소:
1. 아이콘: 😢
2. 감정 이름: "외롭다"
3. 질문: "당신은 누구를\n그리워하는가?"
(나머지는 감정 1과 동일한 구조)
```

## 📝 추가 감정 카드 (선택사항)

같은 방식으로 다음 감정들도 추가할 수 있습니다:

```
1. 지쳤다 - #D4AF37 배경 (밝은)
2. 죄책감 있다 - #3A2A2A 배경
3. 수치스럽다 - #1F3A3A 배경
4. 용서 못함 - #3A1F1F 배경
5. 길을 잃었다 - #2A3A4A 배경
6. 교만해졌다 - #3A3A1F 배경
7. 하나님을 찾고 있다 - #2A4A3A 배경 (가장 긍정적)
8. 잘 모르겠다 - #2A2A3A 배경
```

## 🎬 인터랙션 및 애니메이션

### 스와이프 애니메이션
```
- 드래그 제스처: 좌우 스와이프 인식
- 카드 전환: 300ms easing (cubic-bezier(0.4, 0, 0.2, 1))
- 카드 1 → 카드 2: 화면 왼쪽으로 이동 (X: 0 → -375)
- 다음 카드: 화면 오른쪽에서 들어옴 (X: 375 → 0)
```

### 버튼 인터랙션
```
[경험하기] 버튼:
- 호버: 배경색 밝아짐 (#E8C547)
- 클릭: 카드 확대 애니메이션 (200ms)
  → 감정별 추천 사건 카드 화면으로 진입

[선택하지 않기] 버튼:
- 호버: 텍스트 색상 밝아짐 (#F5F1E8)
- 클릭: 모달 또는 화면 종료
```
