# 핵심 원칙

> **THE WAY는 게임이다.**
>
> **하지만 오락을 위한 게임이 아니라**  
> **하나님의 질문을 경험하는 게임이다.**

따라서 감정 선택 UI는:
- ✅ 게임처럼 느껴져야 함 (진입 장벽 낮음)
- ✅ 심각한 게임 (오락이 아님)
- ✅ 자신의 마음을 마주하게 만드는 UI
- ✅ 하나님의 질문으로 자연스럽게 연결

```
│                                                     │

│  │                                              │  │

│  │                                              │  │
│  │     [꺼지지 않는 질문이 있습니다]            │  │
│  │                                              │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────────────┐                             │
│  │                  │                             │
│  │   두렵다          │  ← 카드 1 (중심)           │
│  │                  │                             │
│  │  당신은 이 순간  │                             │
│  │  무엇을           │                             │
│  │  두려워하는가?    │                             │
│  │                  │                             │
│  │  [경험하기]      │                             │
│  └──────────────────┘                             │
│                                                     │
│  ← 스와이프 또는 다음 →                            │

│                                                     │

│                                                     │
│                 [선택하지 않기]                     │
│                                                     │

```

## 카드 상세 디자인

```
┌────────────────────────────────────────┐
│                                        │
│   두렵다                (이모지 아이콘) │
│                                        │
│   ─────────────────────────────────   │
│                                        │
│   당신은 이 순간                       │
│   무엇을 두려워하는가?                 │
│                                        │
│   [경험하기]      [건너뛰기]          │
│                                        │
└────────────────────────────────────────┘

색상:
- 배경: 진한 네이비 (어두운 감정)
- 텍스트: 크림 색상
- 버튼: 황금색 또는 강조색
- 카드 테두리: 부드러운 그림자

애니메이션:
- 카드가 천천히 떠오르는 듯한 효과
- 스와이프 시 다음 카드로 부드러운 전환
- 경험하기 누르면 카드가 확대되며 Chapter로 진입
```

## 특징

✅ **장점**
- 한 번에 하나의 감정만 집중
- 직관적인 스와이프 인터페이스 (게임다움)
- 각 감정의 핵심 질문이 명확
- 모바일 최적화

❌ **단점**
- 12개 감정을 다 보려면 스와이프 반복 필요
- 전체 구조 파악 어려움

# UI 시안 B: 감정 구름형

## 화면 전체 레이아웃

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ┌──────────────────────────────────────────────┐  │
│  │                                              │  │
│  │     오늘 당신의 마음은 어떠한가요?          │  │
│  │                                              │  │
│  │  [당신의 감정으로 성경 안으로]               │  │
│  │                                              │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│            감정 구름 영역                          │
│                                                     │
│        두렵다        지쳤다                         │
│                                                     │
│    외롭다    ●  ●    길을잃었다                    │
│           하나님      화가난다                      │
│    찾고있다   을     용서못함                      │
│              찾고        ●                          │
│            있다      죄책감있다                    │
│                                                     │
│      교만해졌다    수치스럽다                      │
│                                                     │
│            잘모르겠다                              │
│                                                     │
│  (각 감정 단어가 클릭 가능)                       │
│                                                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│              [선택하지 않기]                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 감정 구름 상세 설명

```
특징:
- 중심에 "하나님을 찾고 있다" (가장 긍정적)
- 바깥쪽으로갈수록 어두운 감정들
- 단어 크기: 관련성/깊이도에 따라 다름
  * 두렵다 (크기: 큼 - 가장 기본적인 감정)
  * 지쳤다 (크기: 중간)
  * 용서못함 (크기: 중간)

색상:
- 밝은 감정 (찾고있다): 따뜻한 색 (금색, 주황)
- 어두운 감정 (분노, 죄책감): 진한 색
- 중성 감정: 중간 톤

인터랙션:
- 감정 단어 호버 시 해당 감정의 설명 보임
- 클릭 하면 해당 감정으로 추천 사건 카드로 이동
- 마우스/손가락 움직임에 따라 구름이 부드럽게 움직임
```

## 특징

✅ **장점**
- 12개 감정이 한눈에 보임
- 게임 같은 인터랙티브 경험 (마우스 추적)
- 시각적으로 아름다움
- 어떤 감정이 있는지 한눈에 파악

❌ **단점**
- 작은 화면에서 읽기 어려울 수 있음
- 구름 배치 알고리즘 복잡도 높음
- 접근성 (키보드 네비게이션) 고려 필요

# UI 시안 C: 나침반형

## 화면 전체 레이아웃

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ┌──────────────────────────────────────────────┐  │
│  │                                              │  │
│  │     오늘 당신의 마음은 어떠한가요?          │  │
│  │                                              │  │
│  │  [나침반을 향해 마음을 돌려보세요]          │  │
│  │                                              │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│                   나침반 영역                      │
│                                                     │
│                    ↑                               │
│                 하나님                             │
│              찾고 있다                             │
│                                                     │
│      길을           →      →    교만              │
│      잃었다  ←───  자신   ←──  해졌다             │
│                  (중심)                            │
│      외롭다                  화가               │
│                              난다              │
│      ↙                                 ↗       │
│   지쳤다    ↖    ↗              ↖    ↗         │
│            용서  죄책감           수치스럽다    │
│            못함  있다         (공포)           │
│            ↓                      ↓              │
│            두렵다                                │
│                                                   │
│                                                   │
│  설명:                                           │
│  위: 초월적 추구 (하나님 찾음)                  │
│  아래: 두려움/공포                              │
│  왼쪽: 고독/약함                                │
│  오른쪽: 자부심/행동                            │
│                                                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│              [선택하지 않기]                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 나침반 상세 설명

```
나침반 의미:
- 중심: "자신" (모든 감정의 출발점)
- 북쪽(위): 하나님을 향함 (영적 지향점)
- 남쪽(아래): 두려움 (인간의 근본 감정)
- 동쪽(오른쪽): 행동/자부심 (외향적)
- 서쪽(왼쪽): 내향성/약함 (내향적)

색상:
- 중심 원: 흰색 또는 크림색 (자신)
- 북쪽: 금색/밝은 색 (영적 방향)
- 남쪽: 진한 파란색/검은색 (두려움)
- 동쪽: 따뜻한 색 (에너지)
- 서쪽: 차가운 색 (침묵)

인터랙션:
- 감정 단어를 클릭하거나
- 나침반의 방향을 누르면 해당 감정 선택
- 마우스 움직임에 따라 나침반 바늘이 방향을 따라감
- 클릭 시 선택한 감정이 중심으로 이동
```

## 특징

✅ **장점**
- 철학적/영적 메시지 강함 ("나침반"은 "하나님을 향함")
- 12개 감정이 의미 있게 배치됨 (방향성)
- 게임다운 인터랙션 (나침반 회전)
- THE WAY의 철학을 시각화

❌ **단점**
- 나침반이라는 메타포가 명확하지 않을 수 있음
- 감정 배치를 이해해야 함
- 구현 난이도 높음

# 추천

## 신속한 MVP (2주)
→ **A. 카드형**
- 구현 빠름
- 직관적
- 게임 경험 충분
- 스와이프는 게임다움

## 중기 (4~6주)
→ **B. 구름형** 또는 **C. 나침반형**
- 시각적 완성도 높음
- THE WAY의 철학 전달
- 플레이어 경험 심화

## 최종 비전
→ **C. 나침반형 (최상)**
- "나침반" = "하나님을 향함"이라는 메타포
- 감정의 배치가 의미를 담음
- 게임이면서도 영적 지향성 명확
- 플레이어가 "자신 → 감정 → 하나님" 여정을 시각화

# 각 시안별 첫 진입 경험

## A. 카드형
```
사용자가 보는 것:
"두렵다" 카드가 떠 있고
"당신은 이 순간 무엇을 두려워하는가?" 질문이 있다
→ 직관적, 게임처럼 느껴짐
```

## B. 구름형
```
사용자가 보는 것:
12개 감정이 구름처럼 떠 있다
자신의 감정을 찾아 클릭한다
→ "내 감정이 여기 있네?" 발견하는 경험
```

## C. 나침본형
```
사용자가 보는 것:
나침반 중심에 "자신"이 있고
북쪽에 "하나님을 찾고 있다"
남쪽에 "두렵다"
→ "내 위치"와 "가야 할 방향"을 동시에 봄
```
