# 1️⃣ CHAPTER 시각화 방식 결정 요청

## 배경
CORE_BIBLE_100 (100개 성경 사건)을 플레이어에게 어떻게 노출할 것인가?

## 3가지 옵션 비교

### ✅ 옵션 A: 카드 스택 (추천)
```
사용자 경험:
- 카드를 스와이프하며 사건 탐색
- 한 번에 1개 사건에 집중
- "다음은 뭘까?" 기대감 형성

장점:
✓ 질문 중심 (헌법 ENGINE 01 준수)
✓ 터치 인터페이스 자연스러움
✓ 모바일 화면 최적화
✓ 심리학적 기대감 ("스와이프")

단점:
✗ 전체 구조 파악 어려움
✗ 100개 중 특정 사건 찾기 어려움
```

**화면 예시:**
```
┌────────────────────────┐
│ 001. 아담과 하와        │
│ "넌 지금 어디 있는가?" │
│ Stage: 입문 | +30점     │
│                        │
│ [경험하기] [건너뛰기]   │
└────────────────────────┘
     ↓ 스와이프 ↓
┌────────────────────────┐
│ 002. 가인과 아벨        │
│ ...                    │
└────────────────────────┘
```

---

### 옵션 B: 시대순 타임라인
```
사용자 경험:
- BC/AD 축에 사건 배치
- 역사의 흐름 따라가기

장점:
✓ 성경 역사의 흐름 이해
✓ 구약/신약 경계 명확
✓ 교육적

단점:
✗ "여정"이 아니라 "역사" 같음
✗ 현대인에게 BC/AD는 추상적
✗ 게임의 철학과 어울리지 않음
```

---

### 옵션 C: 지도/네트워크형
```
사용자 경험:
- 사건들의 관계를 시각화
- 예: "이 사건이 저 사건의 배경"

장점:
✓ 이해도 향상

단점:
✗ 화면 복잡도 높음
✗ 모바일 구현 어려움
✗ "여정감" 부족
```

---

## 🎯 기획팀 결정 사항

**질문:**

1. **옵션 A (카드 스택)로 진행 동의하시나요?**
   - [ ] 네, 옵션 A로 고고
   - [ ] 옵션 B 검토해달라
   - [ ] 옵션 C 검토해달라
   - [ ] 다른 아이디어 있음 → 설명해주세요

2. **카드 스택 보완:**
   - "특정 사건 검색" 기능 필요한가?
   - 예: "모세" 검색 → 관련 사건 3개 표시
   - [ ] 필요 (검색 UI 추가)
   - [ ] 불필요 (스와이프만 사용)
   - [ ] 나중에 (MVP 이후)

3. **"지도 보기" 옵션:**
   - 카드 스택이 기본이되, 우측 상단 [지도보기] 버튼으로 전체 구조 볼 수 있게 할까?
   - [ ] 네, 하이브리드로 (카드 + 지도)
   - [ ] 아니요, 카드만 (단순함)

# 2️⃣ WISDOM POINT 계산 로직 요청

## 배경
Wisdom Point는 **경험치가 아니라 "깨달음의 흔적"**입니다.
(헌법 LAW 05 — Wisdom의 본질)

**현재 안:**
```
CORE_BIBLE_100 각 사건마다 +30~50점

구성:
- 깨달음 선택: +10점
- 기도/고백: +15점
- 현실 퀘스트 완료: +10점
- 소계: +35점 (기본값)
```

## 🤔 기획팀 의사결정 필요 항목

### 1. 포인트 수치 조정
**현재 제안 vs 기획팀 의견**

| 요소 | 현재 | 기획팀 의견 |
|------|------|-----------|
| 깨달음 선택 | +10점 | ? |
| 기도/고백 | +15점 | ? |
| 현실 퀨스트 | +10점 | ? |
| **합계** | **+35점** | **?** |

**질문:**
- 이 수치가 합리적인가?
- 더 높여야 하나? 낮춰야 하나?
- 왜 그렇게 생각하시는가?

### 2. 보너스 포인트
**추가 Wisdom을 획득하는 경우들:**

```
상황 1: 같은 사건을 2번째 진행할 때
- "나선형 깊이"로 다시 경험
- 첫 회: +35점
- 2회: +20점 (보너스는 작음)
- 3회+: +10점 (깨달음 깊어지만 반복)

상황 2: 회개 패턴 5회 반복 후
- Discernment 질문 제공 시
- +50점 보너스 (근본 원인 깨달음)

상황 3: 현실 퀘스트 완료 체크인
- "오늘 했어요" 기록
- +5점 (작은 인정)
```

**질문:**
- 이 보너스 구조가 맞는가?
- 너무 복잡하지 않은가?
- 다른 보너스 조건 있을까?

### 3. Wisdom Point 표시 방식
**게임처럼 보이지 않으면서도 명확해야 함**

현재 제안:
```
❌ "경험치" 같은 표시 금지
❌ "레벨 UP!" 같은 축하 금지

✅ "Wisdom 280점 — 9가지 깨달음 기록됨"
✅ "당신의 영혼은 지금 이 정도의 변화를 경험했습니다"
✅ 포인트가 높을수록 "깨달음이 깊다"는 의미
```

**질문:**
- 이 표현이 적절한가?
- 더 좋은 표현 있나?
- UI상 어디에 어떤 크기로 표시할 것인가?

---

## 📊 예상 분포

100개 사건을 모두 경험하면:
```
기본: 100 × 35점 = 3,500점
보너스 (2회 반복, 패턴 분석 등): +1,200점
총합: ~4,700점

플레이어 타입별:
- 가벼운 플레이: 1,500~2,500점
- 진지한 플레이: 3,500~4,500점
- 심도 있는 플레이: 4,500~4,700점
```

**질문:**
- 이 수치대가 적절한가?
- 너무 높은가? 낮은가?

# 3️⃣ DISCERNMENT ENGINE 트리거 조건 요청

## 배경
플레이어가 같은 종류의 회개를 반복하면,
**근본 원인을 탐색하는 "분별" 질문을 제공합니다.**

현재 안:
```
감지 조건: 같은 주제 회개 5회 이상

예:
- 003 | 가인 | "분노를 다스리지 못함"
- 015 | 삼손 | "욕망에 빠져 후회함"
- 027 | 다윗 | "자부심이 판단을 흐림"
- 035 | 이사야 | "또 같은 실수를 함"
- 045 | 베드로 | "같은 자리에서 실패"

→ 시스템: "어? 이 패턴 자주 보이네?"
→ Discernment 질문 제공
```

## 🤔 기획팀 의사결정 필요 항목

### 1. 트리거 조건
**"5회" 반복이 맞는가?**

| 옵션 | 장점 | 단점 |
|------|------|------|
| **3회** | 빨리 감지 | 너무 자주 질문? |
| **5회** (현재) | 패턴 확실함 | 늦을 수도? |
| **7회** | 충분히 확실함 | 너무 늦음 |
| **유동적** | 플레이 스타일에 맞춤 | 복잡함 |

**질문:**
- 어떤 수치가 가장 좋은가?
- 왜 그렇게 생각하는가?

### 2. 감지 대상
**어떤 종류의 "반복"을 감지할 것인가?**

**옵션 A: 주제 기반** (현재)
```
예: "자부심" 관련 회개들
- 003 가인 | "분노"
- 015 삼손 | "욕망"
- 027 다윗 | "자부심"
- 035 이사야 | "교만"
...
→ 공통 주제: "자기중심적 판단"
```

**옵션 B: 감정 기반**
```
예: "두려움" 관련 회개들
- 005 모세 | "두려움"
- 012 여호수아 | "두려움"
- 028 예레미야 | "두려움"
...
```

**옵션 C: 관계 기반**
```
예: "대인관계" 회개들
- 008 야곱 | "형과의 관계"
- 020 다윗 | "부하와의 관계"
- 042 바울 | "이방인과의 관계"
...
```

**질문:**
- 어떤 기준이 가장 유용한가?
- 복합적으로 감지할 건가? (주제 + 감정)

### 3. Discernment 질문 예시
현재 제안:

```
패턴 감지 후 제공할 질문들 (최소 10개):

Q1: "당신이 자부심 때문에 용서하지 못하는 것은
     정말 자부심 때문일까요?
     아니면 다른 두려움이 숨어 있을까요?"

Q2: "이 깨달음이 정말 하나님께 온 것이라면,
     왜 같은 실수를 반복하고 있나요?"

Q3: "회개 후 변하지 않는다면,
     그것은 회개가 아니라 후회일 수도 있어요.
     무엇이 다른가요?"

Q4: "이것이 정말 당신의 문제인가요?
     아니면 타인의 기준을 내면화한 건 아닌가요?"

... (총 10개)
```

**질문:**
- 이 질문들이 적절한가?
- 더 추가할 질문들 있나?
- 어떤 순서로 제시할 것인가?

### 4. UI/UX
**Discernment 질문을 어떻게 제시할 것인가?**

**옵션 A: 팝업 (현재)**
```
Home 화면에서 갑자기 나타남:

┌────────────────────────────┐
│ 【 당신의 패턴 발견 】      │
│                            │
│ "당신이 자부심 때문에       │
│  용서하지 못한다는 것이    │
│  5번 반복되었습니다."      │
│                            │
│ [깊이 탐색하기]            │
│ [나중에]                   │
└────────────────────────────┘
```

**옵션 B: 전용 화면**
```
"Discernment" 탭 추가
→ 감지된 패턴 목록
→ 클릭하면 질문 가이드 시작
```

**옵션 C: Legacy 기록 중**
```
기도/고백 쓸 때 자동 제안:
"어? 이 패턴 전에도 봤는데?"
[더 깊이 탐색하기]
```

**질문:**
- 어떤 방식이 가장 자연스러운가?
- 강압적이지 않으면서도 눈에 띄게 하려면?
