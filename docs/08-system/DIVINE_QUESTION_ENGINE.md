# PART 1. 엔진 정의

## 1.1 Divine Question Engine이란

> 모든 콘텐츠의 출발점.  
> 하나님이 먼저 질문하신다.

Divine Question Engine은 THE WAY의 심장이다.  
플레이어가 성경 이야기를 읽는 것이 아니라,  
**성경 속 하나님의 질문이 오늘 나에게 던져지는** 경험을 만든다.

## 1.2 질문의 원칙 (헌법 기반)

| 원칙 | 내용 |
|------|------|
| 설교 금지 | 질문은 정답을 알려주지 않는다 |
| 발견 유도 | 플레이어 스스로 깨닫게 만든다 |
| 날것의 언어 | 포장되지 않은 직접적 질문 |
| ? 로 끝남 | 모든 질문은 반드시 ?로 끝난다 |
| 불편함 허용 | 좋은 질문은 며칠 동안 따라다닌다 |
| 현실 착지 | 성경의 질문이 오늘 내 삶에 닿는다 |

# PART 2. 365개 질문 체계

## 2.1 구조 개요

365개 질문은 **무작위가 아니다.**  
성경의 흐름 + 플레이어의 영적 단계 + 삶의 계절을 따른다.

```
365 질문
├── CORE_BIBLE_100 기반 질문 (100개)
│   └── 각 성경 사건의 핵심 질문 1개
├── DAILY_REFLECTION 질문 (200개)
│   ├── 아침 질문 (100개) — 하루를 여는 방향 질문
│   └── 저녁 질문 (100개) — 하루를 돌아보는 점검 질문
└── SEASON_QUESTION 질문 (65개)
    ├── 봄 (16개) — 시작, 씨앗, 결단
    ├── 여름 (16개) — 성장, 시험, 지속
    ├── 가을 (17개) — 수확, 감사, 나눔
    └── 겨울 (16개) — 기다림, 고난, 소망
```

## 2.2 질문 배분 원칙

- 365일 = 매일 1개 질문
- 같은 질문이 반복되지 않는다 (1년 주기)
- 단, **2년차부터는 같은 질문이 다른 깊이로 돌아온다** (나선형 성장)
- 플레이어의 Legacy 데이터를 기반으로 **개인화 추천** 가능 (향후)

# PART 4. Awakening 단계별 질문 연결

## 4.1 단계 개요

플레이어는 5단계 Awakening을 거친다.  
각 단계에서 **다른 깊이의 질문**이 주어진다.

```
STAGE 1 — Entry     (입문)
STAGE 2 — Awakening (각성)
STAGE 3 — Wrestling (씨름)
STAGE 4 — Walking   (동행)
STAGE 5 — Witness   (증인)
```

## 4.2 단계별 질문 특성

### STAGE 1 — Entry (입문)
**질문 특성:** 부드럽고 열려있는 질문  
**목표:** "이 게임은 다르다"는 첫 인식  
**질문 예시:**
- "오늘 하루 가장 기억에 남는 순간이 무엇인가?"
- "하나님에 대해 가장 궁금한 것이 무엇인가?"
- "지금 네 마음이 가장 원하는 것은 무엇인가?"

**활성 카테고리:** CAT_09(감사), CAT_10(말씀과 기도), CAT_07(두려움)  
**질문 깊이:** 1단계 (가장 접근하기 쉬운)

---

### STAGE 2 — Awakening (각성)
**질문 특성:** 자기 인식을 유도하는 질문  
**목표:** "이것은 나의 이야기다"는 경험  
**질문 예시:**
- "이 성경 인물이 느낀 감정이 너와 비슷한 부분이 있는가?"
- "지금 네 삶에서 이 이야기와 겹치는 장면이 있는가?"
- "넌 언제 하나님을 가장 필요로 했는가?"

**활성 카테고리:** CAT_01(정체성), CAT_05(고난), CAT_07(두려움)  
**질문 깊이:** 2단계

---

### STAGE 3 — Wrestling (씨름)
**질문 특성:** 불편하고 직접적인 질문  
**목표:** 진짜 씨름, 첫 번째 회개  
**질문 예시:**
- "넌 무엇을 숨기고 있는가?"
- "반복되는 패턴이 무엇인지 이제 알겠는가?"
- "돌아오지 않는 이유가 무엇인가?"

**활성 카테고리:** CAT_02(회개), CAT_06(교만), CAT_03(순종)  
**질문 깊이:** 3단계 (가장 불편한)

---

### STAGE 4 — Walking Together (동행)
**질문 특성:** 일상과 연결된 지속적 질문  
**목표:** 매일의 동행, 순종이 습관이 됨  
**질문 예시:**
- "오늘 하루 하나님이 어디 계셨는가?"
- "오늘 순종한 가장 작은 것이 무엇인가?"
- "오늘 네 삶이 누군가에게 무엇을 말했는가?"

**활성 카테고리:** CAT_03(순종), CAT_04(관계), CAT_08(소명)  
**질문 깊이:** 4단계 (일상 적용형)

---

### STAGE 5 — Witness (증인)
**질문 특성:** 타인을 향한 질문  
**목표:** 내 여정이 타인의 빛이 됨  
**질문 예시:**
- "네 Legacy가 누군가에게 전해진다면 무엇이 남기를 원하는가?"
- "네가 경험한 하나님을 오늘 누구와 나눌 수 있는가?"
- "네 간증이 완성되지 않아도 이미 시작되었는가?"

**활성 카테고리:** CAT_11(유산), CAT_12(소망), CAT_04(관계)  
**질문 깊이:** 5단계 (가장 깊은)

# PART 6. 질문 생성 규칙

## 6.1 좋은 질문의 조건

| 조건 | 설명 | 체크 |
|------|------|------|
| 1인칭으로 시작 | "넌 ~" 형식 | 필수 |
| ?로 끝남 | 반드시 물음표 | 필수 |
| 15단어 이내 | 간결함 | 권장 |
| 설교하지 않음 | 정답 없음 | 필수 |
| 불편함 허용 | 안전한 질문은 좋은 질문이 아님 | 필수 |
| 오늘에 닿음 | 추상적 신학이 아닌 삶 | 필수 |

## 6.2 나쁜 질문의 패턴

| ❌ 나쁜 패턴 | 이유 | ✅ 대안 |
|------------|------|---------|
| "이 말씀의 의미가 무엇인가?" | 지식 질문 | "이 말씀이 오늘 네 삶에 무엇을 말하는가?" |
| "믿음이 중요하다고 생각하는가?" | 정답 유도 | "넌 무엇을 믿지 못하고 있는가?" |
| "하나님을 사랑해야 하지 않는가?" | 설교형 | "넌 오늘 하나님보다 더 사랑하는 것이 있는가?" |
| "기도를 많이 해야 하지 않겠는가?" | 의무 강요 | "넌 언제 기도가 의무가 아닌 대화였는가?" |

## 6.3 질문 검증 체크리스트

질문 작성 후 반드시 확인:
- [ ] ?로 끝나는가?
- [ ] 정답을 알려주지 않는가?
- [ ] 오늘 내 삶에 착지하는가?
- [ ] 불편함을 주는가?
- [ ] 며칠 동안 따라다닐 수 있는가?
- [ ] LAW 10(최종 목적)을 향하는가?
