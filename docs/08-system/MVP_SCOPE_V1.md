# PART 1. MVP 철학

## 1.1 MVP가 증명해야 하는 것

THE WAY MVP는 기능의 완성이 아니라  
**핵심 가치의 증명**이다.

> "하나님의 질문이 한 사람의 삶을 실제로 바꿀 수 있는가?"

이 하나의 질문에 YES라고 답할 수 있으면 MVP는 성공이다.

## 1.2 MVP 범위 결정 원칙

| 원칙 | 내용 |
|------|------|
| 최소 | 없으면 THE WAY가 아닌 것만 포함 |
| 깊이 우선 | 넓은 기능보다 깊은 경험 하나 |
| 헌법 준수 | LAW 01~14 모두 적용 가능해야 함 |
| 코드 없이 검증 | 가능한 것은 먼저 텍스트로 검증 |

## 1.3 MVP 비포함 항목 (명시적 제외)

다음은 MVP에 포함하지 않는다:

```
❌ 소셜 기능 (공유, 피드, 팔로우)
❌ 챕터 001 외의 CORE_BIBLE_100 챕터
❌ DIVINE_QUESTION_365 전체
❌ 커뮤니티 간증 공간
❌ Legacy 공개 공유
❌ 음성 기도
❌ 알림 고도화 (A/B 테스트 등)
❌ Wisdom 레벨 시스템
❌ 성장 통계 대시보드
❌ 멀티 디바이스 동기화
```

# PART 3. Chapter 0 — 온보딩 설계

## 3.1 Chapter 0의 목적

Chapter 0은 챕터가 아니다.  
**첫 번째 만남의 공간**이다.

> "이 앱은 다른 앱과 다르다"는 것을  
> 설명이 아니라 경험으로 느끼게 한다.

## 3.2 Chapter 0 흐름

```
STEP 1 — 침묵의 시작 (5초)
  화면: 아무것도 없는 검은 화면
  텍스트: (없음)
  목적: 기대와 다른 시작 → "이건 다르다"

STEP 2 — 첫 번째 질문
  화면: 단 하나의 질문
  텍스트: "넌 지금 어디 있는가?"
  서브: (아무 설명 없음)
  행동: 자유 응답 입력 or 건너뜀

STEP 3 — 소개 (최소)
  화면: 3줄
  텍스트:
    "THE WAY는 게임이 아닙니다."
    "하나님을 평생 알아가는 여정입니다."
    "매일 하나의 질문이 당신을 기다립니다."
  행동: 시작하기

STEP 4 — 이름 (선택)
  화면: "어떻게 불러드릴까요?"
  입력: 이름 or 별명 (선택)
  행동: 계속 / 건너뜀

STEP 5 — 시간 설정
  화면: "질문을 몇 시에 받고 싶으신가요?"
  입력: 시간 선택 (기본값: 오전 8시)
  행동: 확인

STEP 6 — 첫 번째 챕터 시작
  화면: "첫 번째 이야기가 시작됩니다"
  텍스트: 창세기 3장 사건 제목 (CORE_001)
  행동: 시작
```

## 3.3 Chapter 0 설계 원칙

| 원칙 | 구현 방식 |
|------|---------|
| 설명 최소화 | 3줄 이상 설명 금지 |
| 질문이 먼저 | 설명 전에 질문이 먼저 온다 |
| 강요 없음 | 모든 입력은 건너뜀 가능 |
| 빠른 시작 | 3분 이내에 첫 챕터 시작 가능 |
| 신뢰 구축 | "이건 달라" 인식이 목표 |

# PART 4. 질문 기능 — MVP 설계

## 4.1 질문 수신 흐름

```
매일 설정된 시간에 알림 발송
    ↓
플레이어가 앱 진입
    ↓
오늘의 질문 화면
    ↓
[응답 선택]
    ├── 묵상 쓰기 → Journal 저장
    ├── 회개 시작 → Repentance 흐름
    ├── 기도 쓰기 → Prayer 저장
    └── 건너뜀   → 기록 없음 (강요 없음)
```

## 4.2 질문 화면 구성 (MVP)

```
화면 구성:

[상단]
  오늘의 날짜
  연결된 성경 본문 (예: 창세기 3장)

[중앙 - 가장 크게]
  질문 텍스트
  "넌 지금 어디 있는가?"

[하단]
  [ 묵상 쓰기 ]    [ 회개 시작 ]
  [ 기도 쓰기  ]   [ 건너뜀   ]
```

## 4.3 MVP 질문 데이터 (초기 30개)

MVP에서는 CORE_BIBLE_100의 첫 30개 질문을 사용.  
이후 확장 예정.

```
Day 01~07  : CAT_01 (정체성) — "넌 누구인가?"
Day 08~14  : CAT_07 (두려움) — "넌 무엇을 두려워하는가?"
Day 15~21  : CAT_02 (회개)  — "넌 무엇을 숨기고 있는가?"
Day 22~30  : CAT_03 (순종)  — "넌 알고 있지만 안 하는 것이 무엇인가?"
```

## 4.4 응답 없음 처리

```
오늘 응답 없음:
  → 다음날 같은 질문 재발송 (1회)
  → 그 다음날 새 질문
  → 정죄 없음. 알림 없음 (단순 재발송만)
```

# PART 5. 회개 기능 — MVP 설계

## 5.1 MVP 회개 범위

MVP에서는 **3단계만** 구현:

```
전체 6단계 중:
✅ STAGE 1 — 질문 (Question)
✅ STAGE 3 — 회개 (Repentance) — 고백
✅ STAGE 5 — 실천 (Obedience) — 퀘스트 제안

❌ STAGE 2 — 깨달음 (별도 화면 없이 질문에 통합)
❌ STAGE 4 — 기도 (기도 기록은 별도 입력으로)
❌ STAGE 6 — 간증 (Legacy 작성으로 대체)
```

## 5.2 회개 흐름 화면 (MVP)

```
SCREEN 1 — 시작
  텍스트: "오늘 마음에 걸리는 것이 있나요?"
  입력:   자유 텍스트 (100자 이내)
  버튼:   [ 계속 ] [ 나중에 ]

SCREEN 2 — 구체화
  텍스트: "그것을 하나님 앞에서 말해보세요"
  서브:   "포장하지 않아도 됩니다"
  입력:   자유 텍스트 (500자 이내)
  버튼:   [ 계속 ]

SCREEN 3 — 전환
  텍스트: "오늘 무엇을 바꾸고 싶나요?"
  서브:   "아주 작은 것이어도 됩니다"
  입력:   자유 텍스트 OR 제안 퀘스트 선택
  버튼:   [ 기록하기 ]

SCREEN 4 — 완료
  텍스트: "기록되었습니다"
  서브:   "모든 기록은 언젠가 간증이 됩니다"
  버튼:   [ Legacy 보기 ] [ 닫기 ]
```

## 5.3 회개 영역 선택 (MVP에서 선택적)

```
선택 가능 태그 (선택 안 해도 됨):
  교만 / 분노 / 두려움 / 순종 거절 /
  용서 거절 / 거짓 / 기타
```

# PART 6. 기록 기능 — MVP 설계

## 6.1 Legacy 화면 구성 (MVP)

```
화면 구성:

[상단]
  "내 여정"
  총 기록 수 / 총 Wisdom Point

[중앙 - 타임라인]
  날짜별 기록 목록
  - 아이콘: 묵상(📖) / 회개(🙏) / 퀘스트(✅) / 기도(💬)
  - 제목 또는 첫 줄 미리보기
  - 연결된 성경 본문

[하단]
  [ + 기록 추가 ] 버튼
```

## 6.2 Legacy 기록 유형 (MVP)

```
MVP에서 지원하는 Legacy 유형:

1. 묵상 기록   (journal)      : 질문 응답 + 자유 묵상
2. 회개 기록   (repentance)   : 회개 흐름에서 자동 생성
3. 순종 기록   (obedience)    : 퀘스트 완료 시 자동 생성
4. 자유 기록   (free_write)   : 플레이어 직접 작성
```

## 6.3 기록 상세 화면

```
SCREEN — 기록 상세:

  [상단]
    날짜 / 유형 아이콘
    연결된 성경 본문 (있는 경우)

  [본문]
    기록 내용 (전체)

  [하단]
    수정 버튼 (내용만, 날짜 불가)
    ← 이전 기록 / 다음 기록 →
```

## 6.4 기록 원칙 (MVP)

```
✅ 수정 가능 (내용)
✅ 조회 가능 (전체 타임라인)
❌ 삭제 불가 (Legacy 원칙)
❌ 공유 불가 (MVP에서는 비공개만)
```

# PART 7. 알림 설계 — MVP

## 7.1 MVP 알림 유형

```
알림 1가지만:
→ "오늘의 질문" 푸시 알림

내용: "오늘의 질문이 도착했습니다"
시간: 사용자 설정 시각 (기본 오전 8시)
빈도: 하루 1회
```

## 7.2 알림 원칙

```
✅ 사용자가 설정한 시간에만
✅ 하루 최대 1회
✅ 응답 없어도 독촉 알림 없음
❌ "오래 접속 안 하셨어요" 유형 금지
❌ 회개 독촉 알림 금지
❌ 게임 복귀 유도 알림 금지
```

## 7.3 향후 알림 확장 (MVP 이후)

```
V1.1:
- 현실 퀘스트 완료 확인 알림 (퀘스트 등록 후 저녁)
- 주간 Legacy 돌아보기 알림 (일요일)

V1.2:
- 기도 응답 확인 알림 (기도 후 7일)
- 계절 질문 알림 (분기별 특별 질문)
```

# PART 9. MVP 성공 기준

## 9.1 정성적 기준

```
MVP가 성공했다면:

✅ 한 명이라도 "이 앱이 나를 불편하게 했다 (좋은 의미로)"고 말한다
✅ 한 명이라도 현실 퀘스트를 실행하고 기록했다
✅ 한 명이라도 회개 후 "가볍다"고 느꼈다
✅ 한 명이라도 Legacy를 보며 "내가 달라졌다"고 느꼈다
```

## 9.2 정량적 기준

```
2주 사용 후 측정:

- Day 7 리텐션: 40% 이상
- 평균 질문 응답률: 50% 이상
- 회개 흐름 완료율: 30% 이상
- Legacy 기록 수: 사용자당 평균 5개 이상
- "오늘의 질문이 도움됐다" 응답: 60% 이상
```
