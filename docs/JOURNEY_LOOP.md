# THE WAY — JOURNEY LOOP
## 8단계 영혼의 순환 구조

**Version:** v1.0 FINAL  
**Date:** 2026-06-10  
**Core:** 감정 → 질문 → 말씀 → 깨달음 → 기도 → 순종 → 기록 → 간증 → (다시 감정)

---

## 🔄 THE WAY는 순환이다

```
THE WAY는 끝나는 게임이 아니다.
THE WAY는 반복되는 여정이다.

한 번 도착하면 끝이 아니라
더 깊이 들어가는 것이다.

사용자는 계속 돌아온다.
왜냐하면 영혼은 계속 변하기 때문이다.
```

---

## 🎯 8단계 Journey Loop

```
        ┌─ 01. 감정 (Emotion)
        │
        ├─ 02. 질문 (Question)
        │
        ├─ 03. 말씀 (Scripture)
        │
        ├─ 04. 깨달음 (Insight)
        │
        ├─ 05. 기도 (Prayer)
        │
        ├─ 06. 순종 (Obedience)
        │
        ├─ 07. 기록 (Record)
        │
        └─ 08. 간증 (Testimony)
            │
            └─ 다시 감정으로 (Emotion)
                (새로운 여정 시작)
```

# 📖 8단계 상세 설명

## Stage 1️⃣: 감정 (Emotion)

### 사용자의 현재 상태를 인식하기

**화면:** SCREEN 01 - 감정 스펙트럼

```
"오늘 나는 [슬픔] 기분이야"
약함: ●●●○○ (Level 3)
```

**사용자의 경험:**
```
"내 감정이 이름이 있네?"
"이걸 표현할 수 있네?"
"혼자가 아닌가?"
```

**심리적 의미:**
```
감정 인식 = 영혼의 시작
(못 본 것은 치유할 수 없다)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 감정... 왜 생겼을까?"
"이것에 대해 뭐라고 말씀하실까?"
```

---

## Stage 2️⃣: 질문 (Question)

### 하나님의 질문과 마주하기

**화면:** SCREEN 05 - 추천 사건 선택

```
"당신이 선택한 [슬픔]의 성경 사건들:

1. 다윗의 광야 도피
   "혼자라고 느껴지나? 나는 거기 있었다"

2. 욥의 고난
   "고통이 뭘 의미하는가?"

3. 나오미의 상실
   "텅 빈 것 같은가?"
```

**사용자의 경험:**
```
"어? 이게 내 상황이네?"
"성경에도 이런 사람들이 있었네?"
"이 사람들은 어떻게 했을까?"
```

**심리적 의미:**
```
질문 = 성경과의 대면
(성경은 네 상황을 안다)
```

**다음 단계로의 자연스러운 이어짐:**
```
"그럼 그 사건이 뭐였어?"
"거기서 뭐가 일어났어?"
```

---

## Stage 3️⃣: 말씀 (Scripture)

### 성경 사건 읽고 만나기

**화면:** SCREEN 06+ - 성경 사건 상세

```
"다윗의 광야 도피

"다윗이 광야로 도망쳤을 때,
그는 혼자라고 생각했다.
하지만 하나님은 그와 함께했다.

시편 23:4
'내가 사망의 음침한 골짜기로 다닐지라도
해를 두려워하지 않을 것은
주께서 나와 함께하심이니라'"
```

**사용자의 경험:**
```
"아, 다윗이 이렇게 느꼈구나"
"그리고 하나님은...?"
"그럼 그 다음은?"
```

**심리적 의미:**
```
말씀 = 영혼의 거울
(내 상황에서 보는 성경)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 말씀이 내게 뭐라고 하는 거야?"
"나는 여기서 뭘 배워야 해?"
```

---

## Stage 4️⃣: 깨달음 (Insight)

### 성경이 내게 말하는 것 받기

**화면:** SCREEN 07 - 깨달음 입력

```
질문: "이 성경 사건에서 당신이 깨달은 것은?"

사용자 입력:
"다윗도 혼자라고 느꼈지만,
하나님은 거기 있었다.

그럼 나도?
나도 혼자가 아닐 수도 있다."
```

**사용자의 경험:**
```
"어? 이게 내가 깨닫는 거네?"
"하나님의 말씀이 내 상황에 뭔가... 걸렸다?"
"뭔가 변하고 있는데?"
```

**심리적 의미:**
```
깨달음 = 영혼의 변환점
(머리에서 가슴으로 내려옴)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 깨달음을... 하나님께 어떻게 말할까?"
"내가 이걸 정말 믿어야 하는데..."
```

---

## Stage 5️⃣: 기도 (Prayer)

### 깨달음을 하나님께 응답하기

**화면:** SCREEN 08 - 기도 입력

```
질문: "당신의 깨달음을 하나님께 기도하세요"

사용자 입력:
"하나님,
제가 혼자라고 생각했는데,
당신이 거기 있었다니...

제가 정말 혼자가 아닌가요?
이제 제 말고 당신을 믿고 싶습니다.

도와주세요."
```

**사용자의 경험:**
```
"아, 나도 기도할 수 있네?"
"깨달음이 기도가 되네?"
"뭔가 다르다... 진짜 대화 같은데?"
```

**심리적 의미:**
```
기도 = 일방적 깨달음에서 관계로
(내가 말하고 → 하나님도 들으시는 것)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 기도... 정말로 믿어야 하는데"
"그럼 이제 어떻게 살아야 해?"
"뭔가 바꿔야 하는 거 아니야?"
```

---

## Stage 6️⃣: 순종 (Obedience)

### 기도와 깨달음을 행동으로

**화면:** SCREEN 09 - 순종 계획 입력

```
질문: "이제 당신은 무엇을 할 것인가?"

사용자 입력:
"이번 주, 나는 혼자만 있지 않겠습니다.

1. 친구에게 연락하기
2. 교회 모임에 나가기
3. 하루에 한 번 이 말씀 읽기"
```

**사용자의 경험:**
```
"아, 이게 순종이구나"
"깨달음이 행동이 되네?"
"진짜로 해봐야겠다"
"뭔가... 무섭긴 한데 가능할 것 같은데?"
```

**심리적 의미:**
```
순종 = 믿음의 첫 발
(말씀이 내 삶에 들어옴)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 순종... 기록해야겠다"
"이게 정말 된다면... 누군가에게 말해주고 싶은데?"
```

---

## Stage 7️⃣: 기록 (Record)

### 영혼의 여정을 남기기

**화면:** SCREEN 10 - Legacy 기록

```
자동 저장 항목:
- 날짜: 2026년 6월 10일
- 감정: 슬픔 (Level 3)
- 기도: "하나님, 혼자라고 생각했는데..."
- 깨달음: "다윗처럼 나도 혼자가 아니다"
- 순종: "이번 주 친구에게 연락하기"

사용자 입력 (1주일 후):
"친구에게 연락했다.
그랬더니 친구도 같은 감정을 겪고 있었다.
우리는 함께 울고 웃었다.
하나님이 이 만남을 주셨다."
```

**사용자의 경험:**
```
"아, 이게 내 기록이네?"
"내가 이렇게 변했네?"
"이게... 간증이 되는구나"
"남겨두고 싶다... 영원히"
```

**심리적 의미:**
```
기록 = 영혼의 역사
(개인의 내적 여정이 객관화됨)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이 변화... 다른 사람도 알아야 하는데?"
"누군가 이 말을 들으면 도움될 것 같은데?"
```

## Stage 8️⃣: 간증 (Testimony)

### 영혼의 변화를 나누기

**화면:** SCREEN 11 - 간증 공유 (선택)

```
당신의 1주일 간증:

"저는 혼자라고 생각했습니다.
고통이 저를 감쌌습니다.
하지만 성경에서 다윗을 만났습니다.

다윗도 혼자였습니다.
하지만 하나님은 거기 있었습니다.

저는 친구에게 연락했습니다.
그랬더니 친구도 같은 감정을 겪고 있었습니다.
우리는 함께 울고 웃었습니다.

하나님이 이 만남을 주셨습니다.

저는 더 이상 혼자가 아닙니다."

→ 커뮤니티 공개 (선택사항)
→ 친구와 공유 (선택사항)
→ 비공개 보관 (기본)
```

**사용자의 경험:**
```
"이게... 간증이네?"
"내 영혼의 여정이... 누군가를 도울 수 있다?"
"이게 왜 감동적인데?"
```

**심리적 의미:**
```
간증 = 영혼의 변화가 신뢰가 되기
(내 이야기가 누군가의 희망이 됨)
```

**다음 단계로의 자연스러운 이어짐:**
```
"이제 좀 나아졌는데..."
"그런데 또 다른 감정이 생겼는데?"
"또 다른 질문이 생겼는데?"

→ 다시 감정으로
```

# 🔁 순환의 완성

## 다시 감정으로

```
1주일 후,
사용자는 또 다른 상황을 마주한다.

예: "친구를 도왔는데, 거절당했어"
    → 분노, 죄책감, 무기력 섞인 감정

사용자는 다시 앱을 연다.

"오늘 나는 [분노] 기분이야"

그리고 다시 시작한다.

감정 → 질문 → 말씀 → 깨달음 → 기도 → 순종 → 기록 → 간증
```

### 순환의 의미

```
1턴: 혼자 → 함께
2턴: 실패 → 용서
3턴: 죄책감 → 해방
4턴: 혼란 → 명확함
...

매 순환마다 영혼은 한 겹씩 벗겨진다.
그리고 더 깊이 들어간다.

이것이 영적 성장이다.
```

# 🎮 게임 메커닉 vs 영혼의 여정

## THE WAY는 "게임"이지만 다르다

### 일반 게임
```
목표 달성 → 스테이지 클리어 → 다음 레벨
보상: 포인트, 뱃지, 레벨 상승

구조: 선형 진행
끝: 게임 오버
```

### THE WAY
```
감정 → 깨달음 → 순종 → 기록 → 간증
보상: 영혼의 변화, 하나님과의 관계

구조: 순환 반복
끝: 없음 (평생 여정)
```

### 핵심 차이

```
게임: "이 스테이지를 깨자"
THE WAY: "내 영혼이 변하고 있다"

게임: 선택적 (하고 싶을 때만)
THE WAY: 필수적 (감정은 계속 생김)

게임: 보상 기반
THE WAY: 변화 기반
```

# 📊 Journey Loop의 구조적 특징

## 1. 자연스러운 이어짐

```
각 단계는 다음 단계를 자연스럽게 유도한다.

감정 → "왜?"
질문 → "뭐라고?"
말씀 → "내게 뭐라고?"
깨달음 → "이제 뭐할까?"
기도 → "정말 해야겠다"
순종 → "이게 되네?"
기록 → "누군가는?"
간증 → "다시 감정"

강압이 없다.
자연스러운 흐름이다.
```

## 2. 심리학적 안정성

```
각 단계마다 사용자가 "충분히 체험"한다.

감정 인식 (자각)
└─ 질문과 마주 (대면)
   └─ 말씀 읽기 (이해)
      └─ 깨달음 (깨침)
         └─ 기도 (관계)
            └─ 순종 (행동)
               └─ 기록 (증거)
                  └─ 간증 (의미)

건너뛸 수 없다.
각 단계가 다음 단계의 기초다.
```

## 3. 영혼의 지속성

```
사용자는 계속 돌아온다.

왜냐하면:
- 감정은 계속 생긴다
- 질문은 계속 생긴다
- 깨달음은 계속 깊어진다
- 간증은 계속 쌓인다

1년 후, 사용자는 47번 돌았다.
그리고 자기가 얼마나 변했는지 본다.

"하나님이 나를 이렇게 변화시키셨다"
```

# 🎯 Journey Loop의 설계 목표

## 1차 방문 (Cold Start)
```
감정 → 질문 → 말씀 → 깨달음 → 기도
(20분)

"오, 성경이 내 상황을 말하고 있네?"
→ 호기심 생김
```

## 2차 방문 (Habit Formation)
```
감정 → 질문 → 말씀 → 깨달음 → 기도 → 순종
(30분)

"아, 이걸 실제로 하면 뭔가 되네?"
→ 기대감 생김
```

## 반복 방문 (Retention)
```
완전 순환 (모든 8단계)
(1주일 + 기록)

"내가 이렇게 변했네?"
→ 의미감 생김
```

## 장기 사용 (Lifetime Value)
```
매달, 매년 순환
(52주 × 1년 = 52번)

"1년에 나는 52번 기도하고,
52번 순종하고,
52번 변했다"

→ 영적 깊이 생김
```

# 🙏 Journey Loop의 신학적 기초

## 성경의 구조

```
구약성경의 순환:

범죄 (감정) → 선지자의 말씀 (질문) → 말씀 (성경)
→ 깨달음 (회개) → 기도 (통회) → 순종 (복귀)
→ 치유 (변화) → 간증 (역사)

그리고 또 다시 범죄로... (순환)

이것이 성경의 역사다.

THE WAY는 개인의 영혼에게
이 구조를 제공하는 것이다.
```

## 신약의 진리

```
야고보서 1:22-25

"너희는 말씀을 행하는 자가 되고
듣기만 하는 자가 되지 말라...

오직 율법을 자세히 들여다보고
행하는 자는... 그 행함으로 복을 받으리라"

THE WAY의 Journey Loop는
이 말씀의 실현이다.

듣고 → 행하고 → 기록하고 → 간증하는 것
```

# 📈 Journey Loop 성공 지표

## 1단계: 진입율
```
감정 선택 후 계속 진행하는 비율: 85%+
(3초 이내 이해, 강압 없음)
```

## 2단계: 심화율
```
깨달음까지 가는 비율: 70%+
(감정 → 질문 → 말씀 → 깨달음)
```

## 3단계: 순행율
```
순종까지 가는 비율: 60%+
(기도 후 실제 행동)
```

## 4단계: 기록율
```
1주일 후 기록하는 비율: 50%+
(간증 작성)
```

## 5단계: 재진입율
```
2주일 내 다시 오는 비율: 80%+
(새로운 감정으로 시작)
```

## 6단계: 장기율
```
12개월 후 활성 사용자: 40%+
(매달 최소 4회 = 52회/년)
```

# 🎬 Journey Loop의 시각화

## 세로로 보기 (깊이)

```
Level 1: 감정 인식 (표면)
         ↓
Level 2: 질문과 마주 (의식화)
         ↓
Level 3: 말씀 (이해)
         ↓
Level 4: 깨달음 (통찰)
         ↓
Level 5: 기도 (변환)
         ↓
Level 6: 순종 (행동)
         ↓
Level 7: 기록 (증거)
         ↓
```
