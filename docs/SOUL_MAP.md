# THE WAY — SOUL MAP
## 영혼 상태 기반 성경 여정 지도

**버전:** v1.0 FINAL  
**작성일:** 2026년 6월 10일  
**목적:** 플레이어의 현재 마음 상태에서 출발해 성경 사건, 질문, 회개, 순종, Legacy로 연결한다.  
**기준:** THE_WAY_CONSTITUTION v1.0 (LAW 03 — 만남 우선)

# 핵심 철학

## 기존 설계 vs 새로운 설계

```
❌ 기존
성경 사건 순서대로 경험
001 아담 → 002 가인 → 003 노아 → ...
(사건 중심)

✅ 새로운 설계
플레이어의 현재 영혼 상태에서 출발
오늘의 마음: "두렵다"
         ↓
    성경 사건 (모세, 여호수아, 베드로...)
         ↓
    하나님의 질문
         ↓
    깨달음 → 회개 → 순종 → Legacy
(마음 중심)
```

## THE WAY의 진정한 목적

> **THE WAY는 성경 사건을 순서대로 나열하는 게임이 아니다.**
>
> **THE WAY는 플레이어의 현재 영혼 상태에서 출발해**  
> **성경 속 하나님의 질문으로 안내하는 여정이다.**
>
> 플레이어는 성경을 구경하지 않는다.  
> **자신의 삶을 들고 성경 안으로 들어간다.**
>
> 모든 기록은 언젠가 간증이 된다.  
> 모든 결정은 언젠가 지혜가 된다.

# PART 1. 첫 화면: 오늘의 마음

## 1.1 화면 설계

```
┌────────────────────────────────────┐
│                                    │
│   오늘 당신의 마음은 어떠한가요?   │
│                                    │
│   ○ 두렵다                         │
│   ○ 화가 난다                      │
│   ○ 외롭다                         │
│   ○ 지쳤다                         │
│   ○ 죄책감이 있다                  │
│   ○ 수치스럽다                     │
│   ○ 용서하지 못하겠다              │
│   ○ 길을 잃었다                    │
│   ○ 교만해졌다                     │
│   ○ 하나님을 찾고 있다             │
│   ○ 잘 모르겠다                    │
│                                    │
│  [선택 안 하기]                    │
│                                    │
└────────────────────────────────────┘
```

## 1.2 원칙

- **강요 금지:** "선택 안 하기" 옵션 항상 제공
- **하나 선택:** 복수 선택 아님 (오늘의 가장 큰 감정 하나)
- **매일 새로움:** 매일 오전 8:00 첫 화면이 이 질문부터 시작
- **비밀 보장:** 선택한 감정이 어디에도 노출되지 않음

# PART 2. 12가지 감정 별 성경 여정

## 감정 1️⃣: 두려움

### 관련 성경 인물/사건
- **모세의 부르심** (출애굽기 3~4장)
- **여호수아의 약속** (여호수아 1장)
- **기드온의 소명** (사사기 6장)
- **베드로의 물 위 걷기** (마태복음 14장)

### 핵심 질문
```
너는 무엇을 두려워하느냐?
내가 너와 함께한다는 것을 믿느냐?
```

### 회개 방향
- 하나님보다 상황을 더 크게 본 두려움
- 순종보다 안전을 선택한 마음

### 현실 퀘스트
```
오늘 두려워서 미루고 있던 일 하나를 작게 시작한다.
(예: 전화, 대화, 결단, 행동 등)
```

### Legacy 기록
```
오늘 나는 무엇이 두려웠고,
하나님은 내게 무엇을 물으셨는가?
```

## 감정 2️⃣: 분노

### 관련 성경 인물/사건
- **가인과 아벨** (창세기 4장)
- **요나와 니느웨** (요나서 전체)
- **다윗과 사울** (사무엘상 24장)
- **예수님의 십자가 용서** (누가복음 23:34)

### 핵심 질문
```
너는 왜 분노하느냐?
네 분노 안에는 어떤 상처가 숨어 있느냐?
```

### 회개 방향
- 판단자가 되려는 마음
- 용서보다 복수를 선택한 마음

### 현실 퀘스트
```
오늘 분노한 사람의 이름을 적고,
그 사람을 위해 1분 기도한다.
```

### Legacy 기록
```
나는 누구에게 분노하고 있으며,
그 분노는 나를 어디로 끌고 가는가?
```

- 하나님이 침묵하신다고 버림받았다고 믿은 마음
- 사람의 인정만 구한 마음

### 현실 퀘스트
```
오늘 혼자라고 느낄 때,
시편 한 구절을 읽고 Legacy에 적는다.
```

### Legacy 기록
```
내 외로움 속에서 하나님은 어디에 계셨는가?
```

- **삭개오** (누가복음 19:1~10)

### 회개 방향
- 수치심을 정체성으로 받아들인 마음
- 하나님의 시선보다 사람의 시선을 더 두려워한 마음

### 현실 퀘스트
```
오늘 '나는 실패가 아니라
하나님의 부르심 안에 있는 사람이다'라고 적는다.
```

### Legacy 기록
```
나는 어떤 수치심에 묶여 있었는가?
```

### 현실 퀘스트

# PART 3. UX 적용 흐름

## 3.1 감정 선택 후 추천 흐름

```
【 오늘의 마음 선택 】
"두렵다" 선택
    ↓
【 추천 여정 카드 표시 】

[1] 모세 — "나는 할 수 없습니다" (출 3~4)
    질문: "너는 무엇을 두려워하느냐?"
    
[2] 기드온 — "정말 저입니까?" (사 6)
    질문: "내가 너와 함께한다는 것을 믿느냐?"
    
[3] 베드로 — "물 위에서 흔들리다" (마 14)
    질문: "두려움 안에 믿음이 있느냐?"
    
[4] 여호수아 — "강하고 담대하라" (수 1)
    질문: "넌 정말 혼자가 아니다"

    ↓ 하나 선택
    
【 Chapter Flow 진입 】
깨달음 → 회개 → 순종 → Legacy
```
