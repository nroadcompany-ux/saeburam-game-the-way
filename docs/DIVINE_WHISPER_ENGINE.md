## 🎯 목적

THE WAY의 속삭임은

**예언이 아니다.**

**새로운 계시도 아니다.**

**성경 말씀을 오늘의 언어로 풀어주는 것이다.**

```
모든 속삭임은 성경에 뿌리를 둔다.

모든 속삭임은 성경으로 이끈다.
```

## 🎨 8대 속삭임 카테고리

### 01. 위로 (Comfort)

**목적:** 상처받은 사람을 안아줌

**톤:** 온화, 공감, 인정

**대표 말씀:**
- 시편 (특히 위로와 눈물)
- 이사야 40-55장 (위로의 예언)
- 요한복음 (예수님의 눈물)

**예시:**
```
"네 눈물은 헛되지 않았다.
 내가 모두 본다."
```

**성경 인물:** 다윗, 욥, 나오미, 예수님

---

### 02. 격려 (Encouragement)

**목적:** 다시 일어나게 함

**톤:** 힘 주는, 활기찬, 긍정적

**대표 말씀:**
- 여호수아 (용사여)
- 느헤미야 (일어나 건축하자)
- 고린도전서 (약할 때 강하다)

**예시:**
```
"아직 끝난 것이 아니다.
 나는 너를 버리지 않았다."
```

**성경 인물:** 여호수아, 느헤미야, 기드온, 바울

---

### 03. 질문 (Question)

**목적:** 생각하게 함

**톤:** 부드러운 도전, 성찰, 미숙한 것이 아님

**대표 말씀:**
- 창세기 3-4장 (너는 어디서 온 것이냐)
- 욥기 (하나님의 질문)
- 복음서 (예수님의 질문)

**예시:**
```
"정말 네가 원하는 것은 무엇이냐?
 두려움에 숨은 것은 아니냐?"
```

**성경 인물:** 아브라함, 야곱, 마리아, 베드로

---

### 04. 회개 (Repentance)

**목적:** 죄를 깨닫게 함

**톤:** 정죄하지 않고, 초청함

**대표 말씀:**
- 선지서 (너의 길을 떠나라)
- 시편 51편 (회개의 시)
- 누가복음 15장 (돌아오다)

**예시:**
```
"너는 그 문제를 남의 탓이라 말하지만
정말 그럴까?
나는 너의 솔직함을 원한다."
```

**성경 인물:** 다윗, 베드로, 세리, 탕자

---

### 05. 순종 (Obedience)

**목적:** 행동으로 옮기게 함

**톤:** 실천적, 구체적, 용기 주는

**대표 말씀:**
- 야고보서 (행함이 따르는 믿음)
- 신명기 (순종의 축복)
- 이사야 (들으라)

**예시:**
```
"오늘 네가 해야 할 작은 한 가지는 무엇이냐?
 모든 것을 변화시키지는 못해도
 그것이 너를 변화시킬 것이다."
```

**성경 인물:** 아브라함, 모세, 막달라 마리아, 베드로

---

### 06. 감사 (Gratitude)

**목적:** 당연함을 깨뜨림

**톤:** 발견, 기쁨, 깨어남

**대표 말씀:**
- 데살로니가전서 5:16-18 (항상 기뻐하라)
- 골로새서 3:15 (감사하는 마음)
- 시편 100편 (감사의 노래)

**예시:**
```
"오늘 받은 것들을 다시 세어보아라.
 거기에 나가 있다."
```

**성경 인물:** 느헤미야, 누가복음의 10명의 문둥이 중 1명, 막달라 마리아

---

### 07. 기다림 (Waiting)

**목적:** 조급함을 내려놓음

**톤:** 침착, 신뢰, 평온

**대표 말씀:**
- 하박국서 (나는 인고하리라)
- 시편 27편 (여호와를 기다리자)
- 로마서 8:25 (소망 중에 기다리자)

**예시:**
```
"씨앗은 땅 아래에서도 자란다.
 너의 계절을 기다려라."
```

**성경 인물:** 아브라함, 야곱, 욥, 엘리자베스

---

### 08. 소명 (Calling)

**목적:** 왜 살아가는지 기억시킴

**톤:** 존엄함, 목적, 초청

**대표 말씀:**
- 에베소서 4:1 (소명에 합당하게)
- 사도행전 (증인이 되라)
- 베드로전서 2:9 (왕 같은 제사장)

**예시:**
```
"너는 우연히 이곳에 온 것이 아니다.
 네 삶 자체가 증거다."
```

**성경 인물:** 모세, 예레미야, 바울, 막달라 마리아

## ✍️ 속삭임 작성 규칙

### 길이
```
✅ 1-3 문장 (short & powerful)
❌ 설교 같은 긴 말씀
❌ 여러 문장의 설명
```

### 톤
```
✅ 1인칭 (하나님 목소리)
✅ 친근함 (존경과 함께)
✅ 현대 언어 (2026년)

❌ 개역개정식 문체
❌ 설교적 톤
❌ 거리감 있는 "신"
```

### 내용
```
✅ 감정 인정
✅ 희망 제공
✅ 행동 초청 (또는 성찰 초청)

❌ 정죄
❌ 강압
❌ 성경보다 높은 해석
❌ 새로운 계시 제시
```

### 출처
```
✅ 항상 성경 구절 제공
✅ 번역본 명시 (표준새번역 권장)
✅ 책, 장, 절 정확히

❌ 출처 없는 위로
❌ 유명한 기독교 저자 인용만 함
```

## 🚫 금지 사항

### 절대 금지

```
❌ 새로운 계시 ("하나님이 말씀하신다" 단정)
❌ 날짜 예언 ("언제까지 고생할 거야" 등)
❌ 하나님 음성 단정 ("나는 이렇게 말한다")
❌ 정치적 주장
❌ 특정 교단만의 주장
❌ 성경 근거 없는 위로
❌ 심리학적 해석만 남기고 성경 빼기
```

### 조심할 것

```
⚠️ 성경과 다른 해석
⚠️ 문화적 편견 섞기
⚠️ 사용자의 상황 단정
⚠️ 너무 일반적인 속삭임 (everyone을 위한 것)
```

## 📝 검증 체크리스트

속삭임 완성 후 반드시 확인:

```
□ 성경 구절이 정확한가? (성경 앱 확인)
□ 출처가 명확한가? (책, 장, 절)
□ 1-3 문장인가? (너무 길지 않은가)
□ 설교 같지는 않은가? (대화 같은가)
□ 정죄하지는 않는가? (초청하는 톤인가)
□ 현대 언어인가? (2026년 말투인가)
□ 하나님 음성 1인칭인가?
□ 감정을 인정하는가?
□ 희망을 주는가?
□ 성경 사건으로 이끄는가? (eventId 있는가)
□ 새 계시 같지 않은가? (보완적인 해석인가)
```
