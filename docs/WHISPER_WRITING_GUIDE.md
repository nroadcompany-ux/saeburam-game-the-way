## 📋 개요

**Whisper:** 사용자의 감정 + 강도를 바탕으로 제공되는 성경 기반 위로 메시지

예시:
```
사용자 입력:
- 감정: 슬픔 (sadness)
- 강도: Level 3 (정말 힘들어요)
- 기도: "하나님, 너무 외롭습니다"

↓ Whisper Engine

출력:
메시지: "너는 혼자가 아니다. 내가 너를 본다. 너의 눈물을 안다."
성경 구절: "주께서 나의 유리함을 계산하셨으니 내 눈물을 담아 두셨다"
출처: 시편 56:8
성경 인물: 다윗
사건 ID: event_045
```

## 🎯 핵심 원칙

### 1. 성경 기반 (필수)
```
❌ "모든 것이 괜찮을 거야"
❌ "시간이 치유해줄 거야"

✅ "너는 혼자가 아니다" (시편 27:10)
✅ "내가 너를 버리지 않는다" (히브리서 13:5)
```

### 2. 감정 인정
```
❌ "슬플 이유가 없어"
❌ "이건 작은 일이야"

✅ "너의 눈물이 유효하다"
✅ "너의 슬픔을 나는 본다"
```

### 3. 성경적 희망 (강제 X)
```
❌ "이제 기도하면 나을 거야"
❌ "믿음이 부족해"

✅ "내가 너와 함께 있다"
✅ "이것도 지나갈 것이다" (고후 4:17)
```

### 4. 특정성 (일반적 X)
```
❌ "하나님은 항상 우리와 함께 있어"

✅ "다윗처럼 너도 광야를 지날 것이다. 하지만 혼자가 아니다"
```

# 📝 Whisper 작성 구조

## 필수 요소 (6가지)

### 1. Message (위로 메시지)
```
요건:
- 길이: 30-100자 (한글)
- 형식: 1-3줄
- 톤: 1인칭 (하나님의 목소리)
- 시제: 현재형 또는 미래형

예시 (좋음):
"너는 혼자가 아니다.
 내가 너를 본다.
 너의 눈물을 안다."

예시 (나쁨):
"혼자라고 느껴질 수 있지만
 하나님은 항상 우리 곁에 있다"
(→ 너무 길고, 일반적)
```

### 2. Scripture (성경 구절)
```
요건:
- 원문 인용 (번역본은 표준새번역 또는 개역개정)
- 길이: 20-100자
- 직접 인용만 (의역 X)

예시 (좋음):
"주께서 나의 유리함을 계산하셨으니
 내 눈물을 담아 두셨다"

예시 (나쁨):
"하나님은 우리의 눈물을 다 아신다"
(→ 의역, 출처 명확하지 않음)

참고: 시편 56:8 (NRSV) 원문
"You have kept count of my tossings;
 put my tears in your bottle"
```

### 3. Reference (성경 위치)
```
형식: "[책] [장]:[절]"

예시:
- 시편 56:8
- 요한복음 11:35
- 이사야 41:10
- 고린도후서 4:17

검증:
- 성경 앱에서 구절 확인
- 번역본 일치 확인
```

### 4. Character (성경 인물)
```
요건:
- 그 구절과 관련된 주요 인물 1명
- 그 인물이 그 감정을 경험했는가?

예시 (좋음):
구절: 시편 56:8
인물: 다윗 ✓ (다윗은 많은 눈물을 흘림)

구절: 욥기 23:10
인물: 욥 ✓

구절: 요한복음 11:35
인물: 예수님 ✓ (예수님도 우셨음)

예시 (나쁨):
구절: 시편 56:8
인물: 솔로몬 ✗ (관련 없음)
```

### 5. EventId (사건 ID)
```
형식: CORE_BIBLE_100의 event ID

찾는 법:
1. CORE_BIBLE_100.md 열기
2. 성경 인물 검색 (예: "다윗")
3. 해당 인물의 event ID 기록

예시:
"다윗의 광야 도피" → event_045
"욥의 고난" → event_050
"예수님의 죽음과 부활" → event_090

생성 규칙:
- 형식: "event_XXX" (3자리 숫자)
- XXX는 CORE_BIBLE_100의 event number
```

### 6. Context (맥락, 내부용)
```
요건:
- 이 whisper를 선택한 이유 (UI 표시 X, 개발/QA 참고)
- 길이: 20-50자

예시:
"다윗도 광야에서 극심한 고통을 경험했음. 그래서 슬픔 Level 3-4에 추천"

예시:
"예수님도 죽음 앞에서 우셨음. 절망적 슬픔(Level 5)의 희망"
```

# 📊 감정별 작성 템플릿

## 감정 매핑

각 감정은 **5단계 강도 × 3-5개 Whisper = 15-25개**

```
슬픔 (Sadness)
├─ Level 1 (가벼워요): 3-5개
├─ Level 2 (꽤 힘들어요): 3-5개
├─ Level 3 (정말 힘들어요): 3-5개
├─ Level 4 (너무 힘들어요): 3-5개
└─ Level 5 (더 이상 버틸 수 없어요): 3-5개

두려움, 분노, ... (9개 감정 모두 동일 구조)
```

# ✍️ 작성 프로세스

## Step 1: 감정 선택
```
다음 9개 감정 중 하나 선택:
1. 슬픔 (sadness) ← 예시
2. 두려움 (fear)
3. 분노 (anger)
4. 외로움 (loneliness)
5. 죄책감 (guilt)
6. 무기력 (exhaustion)
7. 혼란 (confusion)
8. 감사 (gratitude)
9. 평안 (peace)
```

## Step 2: 강도 선택
```
각 감정별 5단계 강도 선택:
- Level 1: 가벼워요
- Level 2: 꽤 힘들어요
- Level 3: 정말 힘들어요 ← 이 단계부터
- Level 4: 너무 힘들어요
- Level 5: 더 이상 버틸 수 없어요
```

## Step 3: 성경 구절 선택
```
1. 관련 성경 인물 떠올리기
2. 그 인물의 사건 찾기 (CORE_BIBLE_100.md)
3. 그 사건의 핵심 구절 찾기
4. 구절 정확성 확인 (성경 앱)

팁: 같은 구절을 여러 강도에서 재활용해도 OK
예: 시편 56:8은 슬픔 Level 1, 2, 3 모두에서 사용 가능
```

## Step 4: 메시지 작성
```
원칙 (다시 한 번):
1. 1인칭 (하나님 목소리)
2. 감정 인정 + 희망 제공
3. 30-100자 (한국어)
4. 성경의 의도 유지

팁: 어렵게 쓰지 말기
"너는 혼자가 아니다" ✓
"고독감의 극복을 위해서는 신앙적 동반자의 중요성을 인식해야 한다" ✗
```

## Step 5: Whisper ID 생성
```
형식: {감정}_{강도}_{순번}

예시:
- sadness_1_1 (슬픔 Level 1, 첫 번째)
- sadness_3_2 (슬픔 Level 3, 두 번째)
- fear_5_1 (두려움 Level 5, 첫 번째)
```

## Step 6: 검증
```
체크리스트:
□ 성경 구절이 정확한가? (성경 앱에서 확인)
□ 구절과 인물이 연결되는가?
□ 메시지는 감정을 인정하는가?
□ 메시지는 희망을 주는가?
□ 메시지가 너무 길지는 않은가? (100자 이내)
□ EventID가 실제로 존재하는가? (CORE_BIBLE_100 확인)
```

# 📞 문의 사항

**어떤 성경 구절을 사용해야 할까?**
→ CORE_BIBLE_100.md의 Insight Points 참고

**다양성이 부족해 보일 때는?**
