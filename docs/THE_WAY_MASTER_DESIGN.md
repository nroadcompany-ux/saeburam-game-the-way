## 1. 플랫폼 최종 정의

### THE WAY는 무엇인가

> **게임은 수단이다. 회심은 목적이다.**

THE WAY는 성경 RPG가 아니다.

THE WAY는 **한 영혼이 하나님을 찾아가고, 하나님을 만나고, 하나님의 뜻을 깨닫고, 순종하며 살아가는 여정을 게임의 형태로 경험하는 플랫폼**이다.

| 구분 | 내용 |
|------|------|
| **형태** | 성경 기반 인터랙티브 스토리 게임 |
| **핵심 목적** | 회심 (Conversion) — 하나님을 만나고 예수님을 따르게 됨 |
| **수단** | 게임 메커닉, 감정 체험, 하나님의 질문 |
| **최종 결과** | 삶의 변화 — 순종하며 살아가는 사람 |

### 한 문장 정의

THE WAY는

- 성경 RPG
- 영적 성장 플랫폼
- 삶의 기록장 (영적 자서전)
- 회개와 순종 훈련 시스템
- 하나님의 질문 엔진
- **실제 사역과 연결된 사랑의 플랫폼**

이다.

|------|-----------|-----------|

## 4. 전체 엔진 시스템

THE WAY는 12개 엔진 위에서 작동한다.

### 최상위 엔진

#### Encounter Engine — 하나님과의 만남

> 질문의 목적도, 깨달음의 목적도, 회개의 목적도 아니다.
> **모든 엔진의 최종 목적은 "하나님을 만나는 것"이다.**

이 엔진이 모든 엔진 위에 있다.

### 엔진 상세 설명

#### God's Heart Engine — 예시: 엔게디 동굴

| 요소 | 내용 |
|------|------|
| **사건** | 다윗이 사울을 죽일 기회를 얻음 |
| **감정** | 분노 · 억울함 · 복수심 |
| **하나님의 마음** | "나는 네가 분노에 먹히길 원하지 않는다." |
| **하나님의 뜻** | "나를 신뢰하는 사람으로 성장시키고 싶다." |
| **하나님의 질문** | "너는 지금 복수를 원하는가? 아니면 나를 신뢰하겠는가?" |
| **깨달음** | "사울이 문제가 아니었다. 내 안의 분노가 문제였다." |

#### Biblical Immersion Engine — 성경 몰입 체험

읽는 성경 ✗ → 체험하는 성경 ✓

| 체험 예시 |
|---------|
| 모세 옆에서 홍해 앞에 서기 |
| 다윗과 함께 동굴에 있기 |
| 베드로와 함께 물 위 걷기 |
| 십자가 아래 서기 |

플레이어는 성경 역사 속으로 들어가 **직접 보고, 직접 듣고, 직접 선택**한다.

#### Player State Engine — 현재 상태에서 시작

THE WAY는 성경 이야기로 시작하지 않는다. **현재 플레이어의 상태로 시작한다.**

초기 상태 후보: 분노 · 두려움 · 상처 · 외로움 · 우울 · 중독 · 교만 · 욕심 · 절망 · 불안 · 시기 · 미움

#### Silence Engine — 하나님의 침묵

> 성경에는 응답만 있는 것이 아니다.
> 침묵도 있다. 기다림도 있다. 고난도 있다.

플레이어의 질문:
- 왜 하나님은 응답하지 않으시는가?
- 왜 기도해도 변하지 않는가?
- 왜 기다려야 하는가?

→ 이 질문들이 챕터가 된다.

#### Reality Quest Engine — 현실 퀘스트

깨달음은 끝이 아니다. **현실에서 실천해야 한다.**

| 퀘스트 유형 | 예시 |
|-----------|------|
| 관계 회복 | 용서하기 · 가족에게 사랑 표현 |
| 신앙 실천 | 기도하기 · 성경 읽기 · 교회 방문 |
| 이웃 섬김 | 봉사하기 · 기부하기 |
| 감사 실천 | 감사 일지 쓰기 |

#### Calling Engine — 매일 부르심

매일 하나님께서 부르신다.

> "오늘도 나와 함께 걷겠느냐?"
> "오늘 너에게 맡긴 사람은 누구냐?"
> "오늘 무엇을 내려놓겠느냐?"

#### Spiritual Biography Engine — 영적 자서전

플레이어의 여정이 자동으로 기록된다.

```
2026년 — 분노와 싸움. 하나님을 처음 찾음.
2027년 — 용서를 배움.
2028년 — 순종 시작.
2030년 — 첫 간증.
```

## 7. 콘텐츠 설계 원칙

### 예수님 중심성 (Jesus Center Rule)

모든 챕터 · 모든 질문 · 모든 깨달음 · 모든 순종 · 모든 기록은 **결국 예수님께 향해야** 한다.

다윗은 목적이 아니다. 모세는 목적이 아니다. 바울은 목적이 아니다. **예수님이 목적이다.**

### 은혜 균형 법칙 (Grace Balance Rule)

THE WAY는 죄만 보여주는 게임이 되어서는 안 된다.

```
잘못된 구조: 죄 → 죄 → 죄 → 죄

올바른 구조: 죄 발견 + 은혜 발견
```

| 죄 카테고리 | 대응 은혜 카테고리 |
|-----------|-----------------|
| 분노 | 용서 |
| 교만 | 겸손 |
| 거짓말 | 진실 |
| 두려움 | 용기 |
| 절망 | 소망 |
| 미움 | 사랑 |
| 불안 | 평안 |
| 탐욕 | 나눔 |

### 선택과 결과

```
선택 → 결과 → 깨달음
```

"옳은 선택"이 아니라 **"나의 선택"**이 중요하다.

### 하나님의 침묵

침묵 · 기다림 · 고난도 챕터로 다루어야 한다.

## 9. 사역 플랫폼 구조

THE WAY는 게임 앱이면서 동시에 **사역 플랫폼**이다.

```
플레이어 (개인 영적 여정)
        ↓
  THE WAY 플랫폼
   ┌─────────────────────────────┐
   │  게임 콘텐츠                 │ ← 챕터, 인터랙션, 선택
   │  삶의 기록장 (영적 자서전)    │ ← 깨달음, 기도, 순종 일지
   │  현실 퀘스트                 │ ← 실천 미션 연결
   │  커뮤니티                    │ ← 교회, 소그룹, 멘토
   │  사역 연결                   │ ← NGO, 선교단체, 섬김 기회
   └─────────────────────────────┘
        ↓
  삶의 변화 (회심 → 제자도 → 사역)
```

### 플랫폼 참여자

| 참여자 | 역할 | 가치 |
|--------|------|------|
| **플레이어** | 영적 여정 경험 | 하나님 발견, 삶 변화 |
| **교회/목회자** | 콘텐츠 파트너 | 전도/양육 도구 |
| **NGO/선교단체** | 사역 연결 | 검증된 현장 기반 |
| **투자자/후원자** | 재정 파트너 | 투명한 사역 기여 |

## 10. NGO 투명성 시스템

### 문제 인식

> 요즘 사람들은 NGO에 대한 불신이 많다.
> "본인들 운영비에 다 쓴다. 월급만 올려준다."

이 불신은 사실에 근거한 경우가 많다. THE WAY 플랫폼이 연결하는 사역단체들도 이 문제를 피해갈 수 없다.

### 해결 방향

THE WAY는 파트너 NGO/사역단체에게 **투명성 인증 시스템**을 제공한다.

```
전체 후원금
  ├── 10% 이하: 운영비 (근거 공개)
  └── 90% 이상: 혜택/사역 사용 (증거 첨부)
```

### 투명성 인증 시스템 — 기능 설계

#### 재정 대시보드 (단체 공개 페이지)

| 항목 | 내용 |
|------|------|
| 총 후원금 | 기간별 수신 총액 |
| 운영비 비율 | % + 세부 항목 (인건비, 임대, 행정) |
| 사역 사용액 | % + 세부 항목 (현장, 물품, 교육) |
| 실시간 업데이트 | 월별 자동 갱신 |

#### 증거 첨부 시스템

| 증거 유형 | 예시 |
|-----------|------|
| **현장 영상** | 급식 배분, 의료 지원, 교육 현장 |
| **이미지** | 수혜자 사진 (얼굴 비공개 가능), 시설 사진 |
| **영수증/문서** | 지출 증빙 (선택 공개) |
| **수혜자 증언** | 텍스트/음성 (익명 가능) |

#### 인증 레벨

| 레벨 | 조건 | 배지 |
|------|------|------|
| **Bronze** | 재정 대시보드 공개 | 투명 단체 |
| **Silver** | 운영비 10% 이하 + 증거 50% 첨부 | 검증 단체 |
| **Gold** | 운영비 10% 이하 + 증거 80% 이상 + 외부 감사 | 신뢰 파트너 |

#### 플레이어와의 연결

플레이어가 THE WAY에서 순종/나눔 챕터를 완료하면:

```
"오늘 이 챕터에서 나눔에 대해 배웠습니다.
Gold 인증을 받은 단체에 후원하시겠습니까?
이 단체는 운영비 8%만 사용하며, 현장 증거를 공개합니다."
```

→ 게임 내 영적 여정이 **실제 사역 참여**로 연결됨.

→ Love Engine의 핵심 기능이 된다.
