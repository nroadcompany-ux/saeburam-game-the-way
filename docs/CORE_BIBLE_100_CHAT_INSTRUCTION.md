## THE WAY 프로젝트 핵심 철학

**게임은 수단이다. 회심은 목적이다.**

THE WAY는 성경 RPG가 아니다.
한 영혼이 하나님을 찾아가고, 하나님을 만나고, 하나님의 뜻을 깨닫고, 순종하며 살아가는 여정을 게임의 형태로 경험하는 플랫폼이다.

---

## 절대 원칙 (위반 금지)

1. **설교하지 않는다** — "이렇게 살아야 한다"는 말 금지
2. **정답을 설명하지 않는다** — 발견하게 만든다
3. **감정은 날것이어야 한다** — 분노, 수치심, 절망을 미화하지 않는다
4. **하나님의 질문이 최우선이다** — 모든 사건은 반드시 질문으로 끝난다
5. **하나님은 1인칭으로 말한다** — "나는 ~"으로 시작
6. **현실과 연결한다** — 오늘 내 삶에 직접 착지해야 한다
7. **모든 사건은 예수님을 향한다** — 다윗, 모세, 바울이 목적이 아니다

## 각 사건의 구조 (반드시 이 순서대로)

```
## [번호]. [사건명] — [부제]

**성경 구절:** 
**인물:** 
**장소:** 
**시대:** 

### 인간의 감정
(2~4개 감정, 각 1줄 설명 — 날것으로)

### 하나님의 마음
(1인칭 "나는 ~"으로 시작. 하나님의 시선에서)

### 하나님의 뜻
(이 사건을 통해 하나님이 하려는 것)

### 하나님의 목적
(더 큰 그림, 역사적 맥락)

### 깨달음 포인트
(선언형 아닌 발견형 — "~일 수 있다", "~인가?" 형식)

### 현실 적용
(오늘 내 삶에 연결 — 2~3가지, 구체적으로)

### 현실 퀘스트
(구체적 행동 1~3개)

### Wisdom Point
(숫자 10~50점 + 이유 한 줄)

### 하나님의 질문
> (반드시 "?"로 끝나는 질문. 플레이어의 내면을 찌르는 것. 이것이 사건의 핵심)
```
