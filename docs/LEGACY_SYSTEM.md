## 🎯 Legacy의 정의

Legacy는 **단순 기록이 아니다.**

Legacy는 **"하나님과 나의 역사"**이다.

```
기록 (Record) ≠ Legacy
        ↓
Legacy = 하나님의 손길을 보는 것
Legacy = 변화의 증거
Legacy = 간증의 시작
```

---

## 📖 Legacy의 의미

### 기록의 수준

```
Level 1: 일기 (내가 뭘 했는지)
Level 2: 반성 (내가 뭘 배웠는지)
Level 3: 간증 (하나님이 뭘 하셨는지) ← THE WAY의 Legacy
```

THE WAY의 Legacy는 **Level 3**입니다.

사용자가 기록하는 것은:
- 내 감정이 아니라
- **하나님의 손길**
- **변화의 증거**
- **내일의 간증**

## 💾 Legacy 저장 항목

각 성경 사건을 마친 후 사용자가 기록하는 항목:

### 1️⃣ 날짜 (자동 기록)
```
저장: ISO8601 format
표시: "2026년 6월 10일 화요일"
용도: 시간의 흐름 추적
```

### 2️⃣ 감정 (기록)
```
선택된 감정: sadness (Level 3)
표시: "😢 슬픔 (꽤 힘들어요)"
용도: 감정 변화 추적
```

### 3️⃣ 기도 (선택사항)
```
사용자 입력: "하나님, 너무 외롭습니다..."
공개: 비공개 (default)
용도: 개인의 영혼 대화
```

### 4️⃣ 깨달음 (필수)
```
질문: "이 성경 사건에서 당신이 깨달은 것은?"
입력: 사용자가 직접 작성 (100-500자)
예시: "다윗도 광야에서 혼자라고 느꼈지만, 하나님은 항상 있었다."
용도: 성경을 자신에게 해석하기
```

### 5️⃣ 순종 (필수)
```
질문: "이제 당신은 무엇을 할 것인가?"
입력: 구체적인 행동 계획 (1주일 내)
예시: "이번 주 한 번은 혼자가 아닌 누군가를 찾아 대화하기"
용도: 행동으로 옮기기 (야고보서 1:22)
```

### 6️⃣ 간증 (최종)
```
질문: "1주일 후, 당신의 순종으로 어떤 변화가 생겼는가?"
입력: 변화의 기록 (300자+)
예시: "혼자 있고 싶은 마음이 있었지만, 친구에게 연락했다. 
그랬더니 친구도 같은 감정을 겪고 있었다. 
우리는 함께 울고 웃었다. 
하나님이 이 만남을 주셨다."
용도: 변화의 증거, 내일의 간증
```

## 🙏 왜 Legacy가 중요한가?

### 기본 철학

> **"모든 기록은 언젠가 간증이 된다"**

### 5가지 이유

#### 1. 변화의 증거 (Proof of Change)
```
"당신은 변했다."

숫자가 증명한다.
데이터가 증명한다.
12개월 그래프가 증명한다.

의심할 수 없는 변화.
```

#### 2. 하나님의 손길을 보기 (God's Work)
```
Legacy를 보면서 사용자는 깨닫는다:

"이것은 내가 한 게 아니라
하나님이 하신 일이다."

내 순종은 겨우 한 발씩이었지만,
하나님의 손길은 흔적이었다.
```

#### 3. 미래의 희망 (Hope for Tomorrow)
```
힘들 때, Legacy를 본다.

"저번엔 이 감정에서 벗어났어.
그럼 이번에도 벗어날 수 있어."

과거의 기록이 미래의 확신이 된다.
```

#### 4. 누군가의 간증 (Someone's Testament)
```
당신의 변화는
누군가의 영감이 된다.

"저 사람도 이렇게 변했어?
그럼 난 어쨌든 안 되는 걸까?"

NO.

당신의 간증은 누군가의
"가능성"이 된다.
```

#### 5. 하나님과의 역사 (God's History with Me)
```
Legacy는 단순 기록이 아니다.

Legacy는
"하나님이 나와 함께하신 역사"이다.

5년 후,
당신은 말할 수 있을 것이다:

"하나님이 나를 이렇게 변화시키셨다."
```
